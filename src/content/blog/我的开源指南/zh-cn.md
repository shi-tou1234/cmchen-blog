怎么看待我的开源项目。GitHub 上目前 11 个仓库，分三类：博客与主页、学习与电子信息工具箱、桌面效率工具。下面逐个说清楚它们能干什么、怎么用、用的时候注意什么。

* * *

## 博客与主页

**cmchen-blog** 是一个功能比较完整的静态博客，基于 Astro 构建，文章用 Markdown 写。它是从 motues 的 Momo fork 过来深度改造的：暖纸配色和中文衬线字体体系、整套移动端交互重做、一套可扩展的自定义 Markdown 样式，再加上不需要本地环境的 GitHub 在线管理后台。除了 Frontmatter 元数据、文章分类、标签系统、时间线归档页、阅读进度条、预计阅读时间、文章置顶，还有 RSS 订阅、数学公式（KaTeX / Typst）、代码高亮（Shiki）、全文搜索（Pagefind）、字号 80%–150% 滑杆调节（偏好写进 localStorage 长期记住）、全屏沉浸阅读、深色模式跟随系统、AOS 滚动动画、粒子背景、页面切换过渡动画，以及音乐卡片、GitHub 卡片、引用块、提示框、推导过程浮层这些自定义 Markdown 组件。数据可视化有旅行地图城市标记和 Git 提交热力图，社交分享带完整的 Open Graph / Twitter Card。移动端专门重做过：收拢式浮动按钮，一个圆钮展开菜单、目录、返回上一页、评论、回顶，配底部导航栏和独立的 `/tools` 工具栏页。

用的时候，clone 仓库到本地，按 README 里的步骤改 `astro.config.mjs` 里的 `site` 和 `base` 成你自己的部署地址，推到 GitHub 后把仓库 `Settings → Pages` 的 Source 设成 GitHub Actions，就会自动构建发布。后台地址是 `/admin/`，第一次进入时设置密码，之后写文章、改站点配置都在后台完成，不需要碰代码。

注意几个问题：预览图片的路径如果换成自己的仓库，需要把 README 和配置里的 `shi-tou1234/cmchen-blog` 替换成你的用户名和仓库名，否则图片会裂。后台写的文章自动保存到浏览器 localStorage，发布前建议本地先 preview 一遍确认格式没问题。站点默认不开放搜索引擎收录（`src/layouts/Layout.astro` 里对 robots / googlebot / bingbot 都写了 noindex），如果你想被收录，得自己改这几行。

**cmchen-blog-starter** 是上面的"抽真空版"。功能框架和工程配置全部保留，文章、关于页、个人资料、工具栏链接、旅行地图、音乐播放列表全部清空。你 clone 下来填自己的内容就能直接用。如果你觉得完整版太臃肿，这个更合适起步。配置方式跟完整版一样，改 `astro.config.mjs` 里的站点地址，推上去部署。

这两个仓库的区别就是：starter 是开箱即用的空壳，blog 是功能齐全的成品，也是 starter 的功能参考。

**cmchen-page** 是我的个人主页，React 19 + Vite 构建，暗夜放映室基调：深蓝夜空、衬线巨字、香槟金色温。最显眼的是背景——五段实拍夜景视频按栏目接力成为一段连续背景，栏目交界处让两条真实视频继续运动并交叉溶解。视频是 1600×900、24fps、无音轨、全关键帧编码，做过 `nlmeans` 降噪、`delogo` 水印清理和轻度锐化，合计约 4.1 MB。播放驱动是混合的：滚动时把滚动进度映射成视频播放头的纯 seek 刮擦，静止 650 毫秒后当前段以 1× 原速自动播放（24fps 原生送帧，不慢放），两态交接时把播放头差记成一次性 drift 随滚动平滑衰减归零——这条专门是为了修掉"滚轮一动背景就往回跳一下"。非当前段一律 `preload="none"`，滚到前 1.2 屏才预热。

动效上最花心思的是"不共用一条缓动"：拆成入场急停的 snap、回弹过冲的 spring、大位移缓落的 settle 三族，按语义分配，每个区块的 burst / rest / cascade 段性和错位时长都写死在 `PROGRESS.md` 的节拍表里。还有个叫"边界承载"的做法——七个区块交界处有活过去的元素，下一节的幽灵水印字放大 1.07×、半透明从上一节散场中浮出；Preloader 是电影开场，logo 逐字打出后 Hero 巨字弹入，每次刷新完整播放 2.2 秒；Hero 是 192svh 跑道加 sticky 舞台，滚轮驱动内容层下沉缩放逐字散隐。粒子尘埃只有 19 颗，静止约 1 秒内完全冻结，快滚时沿真实运动方向拉出细痕。

内容全部外置成 `src/data/content/` 下的十一份 JSON，改文案不碰组件；`#/admin` 有可视化后台，表单填完直接通过 GitHub Contents API 提交到你的仓库，Actions 自动重新部署。旅行足迹数据跟博客同源：`scripts/fetch-travel.mjs` 在 dev/build 前从博客仓库的 `about-personal.ts` 里提取 58 城写成快照，你在博客后台改足迹，主页下次构建自动跟上。

用的时候，clone 下来 `npm install` 后 `npm run dev`，Windows 双击 `start.bat` 一键启动。想改成自己的主页，把 JSON 里的资料换掉、换掉 `public/videos/` 里的背景视频就行。推 main 分支后 Actions 自动部署到 GitHub Pages。

注意：后台密码是 PBKDF2 哈希存在 `public/admin-security.json` 里，忘了只能跑 `node scripts/gen-admin-hash.mjs <新密码>` 重新生成；进后台要填 fine-grained Personal Access Token，只勾本仓库的 Contents: Read and write 就够，权限给多了没必要；关于区的富文本只解析 em/strong/b/i/br 这几个标签，塞原始 HTML 不会生效；旅行足迹要在博客那边改，主页只能读；运行时抓博客最新文章依赖博客站与主页同源，博客绑了自定义域名就得补 CORS；`shots/` 下还留着一套验收探针脚本，动效这种机器判不了手感的东西靠它们用数字盯住，改完动效跑一遍比自己盯屏幕靠谱。

## 学习与电子信息工具箱

**cmchen-study-platform**（学习工具台）是四个工具合一的纯前端页面，卡西欧 fx-991 风格的深色 UI，零依赖、零网络请求。顶栏四栏目切换：科学计算器（标准、方程、矩阵、向量、统计、微积分、复数、进制、逻辑、表格、工具共 11 种运算模式）、布尔化简（真值表 → Quine-McCluskey → 最简表达式，最多 10 输入 10 输出，自动标注异或同或）、实验记录（按实验项目录入数据、拍照留证、导出 CSV）、数据处理（统计分析、图表绘制、线性/多项式拟合）。

这个仓库的前身是我最早分开写的 jisuan（计算器）和 zhenzhibiao（真值表化简），后来发现它们本来就是电路课一对搭档，就合并成了一个工具台，顺带补上了实验记录和数据统计——大物、模电实验报告需要的东西齐了。

直接浏览器打开 `index.html` 就能用，在线版挂在 GitHub Pages 上。栏目选择记在浏览器里，也支持 URL 深链接直达某一栏。

注意：角度制/弧度制切换会影响三角函数结果，算完记得切回来；布尔化简的符号约定是 `!` 取反、`&` 与、`#` 或（最简表达式）、`+` 或（标准形式），NOT 跟 `!A` 那种传统写法不一样；实验记录和数据处理的数据存本地浏览器，清缓存前先导出一份 CSV。

**links** 是一个浏览器端的网页链接导航，专门给电子信息学科用的。分 8 个分类：芯片选型（半导小芯、立创商城）、EDA 工具、竞赛资源、求职准备。每张卡片有图标、简介、标签，点进去直接跳转。支持关键词搜索（输入名称、描述或标签实时过滤）、本地收藏（星标按钮，localStorage 持久化）、分类筛选带计数徽章、瀑布流布局、移动端三档适配。视觉上是 8 层径向渐变叠出来的 Mesh 渐变背景配模糊旋转，卡片是玻璃拟态加彩虹渐变外发光悬停边框，再叠一层 SVG fractalNoise 噪点和跟随鼠标的粉色光晕。

直接用浏览器打开 index.html 就能用，不需要装任何东西，不需要后端。

注意：无第三方网络请求，Google Fonts 已经换成本地自托管的 woff2，大陆网络环境直开不阻塞；CSP 走 meta 限制脚本、样式和字体来源，`file:` 方案是为了兼容直接双击打开；真部署到线上建议再补服务器级的 CSP、Referrer-Policy、X-Content-Type-Options；收藏夹数据存在浏览器 localStorage 里，换浏览器或清数据会丢，没有云端同步。

**box**（BENCH-01）是焊接元器件的库存管理工具，纯静态前端，本地优先。前台是只读查询页，后台是独立路由，登录后才能维护数据。你在实验室拆了电阻电容、收了芯片，往后台录入名称、种类、封装、位置、数据手册链接和备注，之后找东西的时候搜一下名称、封装、位置或备注就能出来。查询页有按种类筛选、网格/表格双视图，仪表盘显示元器件种类和近期变动，还有分类分布条形图、封装类型占比环形图，点条目弹详情。数据手册链接支持跳转。

用的时候，推荐部署到 GitHub Pages（Source 选 `main` 分支根目录），前台在根路径、后台在 `/admin/`。想本地看，`python -m http.server 8000` 或 `npx serve .` 起个静态服务器就行。

注意：因为用了 ES Modules，直接双击 `file://` 打开在部分浏览器里会失败，要走 HTTP。数据只存在当前浏览器的 localStorage（`solder_pm.components.v1`），清浏览器数据或者换设备会丢，建议定期用后台的 Gist 同步配 GitHub Token 备份。管理密码只存本地，忘掉了需要手动清浏览器数据重置。首次进入 `/admin/` 时才设置密码。

**yulan**（预览）是一个浏览器端的 Markdown 实时编辑器，左边写右边渲染。基础能力之外，它在标准 GFM 之上自己加了一整套扩展语法，而且样式可以嵌套（比如 `!!==模糊彩虹==!!`）：

- `++文本++` 彩色下划线、`!!文本!!` 模糊遮蔽（悬停或点击才清晰，适合剧透）、`==文本==` 彩虹渐变
- `{汉字}(hàn\|zì)` 拼音注音，Ruby 逐字对应
- `[^1]` 脚注，文末自动编号并支持跳回
- `:::quote` 引用卡片，配 `<right>` 标签写右对齐落款
- 五种提示框，标题都能自定义
- `:::derivation` 推导容器，hover 前一个公式才展开
- `::github{repo="用户/仓库"}` 仓库卡片，描述、Star、Fork、语言自动拉
- `::music{id="歌曲ID"}` 网易云音乐卡片，封面、歌名、艺术家自动拉

编辑器这边是双向选区联动、Tab/Shift+Tab 缩进、实时字数统计、20 多个带 tooltip 的快捷插入按钮，还有打印样式（隐藏工具栏只打预览）。主题亮色是暖纸色、暗色是深蓝紫，偏好自动记忆。

直接浏览器打开 index.html 就能用，不需要任何依赖，不需要服务器。

注意：marked、KaTeX、Highlight.js、DOMPurify 全走 CDN，首次打开必须联网，之后断网也能正常编辑预览；GitHub 卡片和音乐卡片依赖外部 API，断网时加载不出来；本地存储只存在当前浏览器，换浏览器会丢，导出之前建议先点下载存一份。内容经过 DOMPurify 清理 HTML，但如果粘贴带格式的富文本，可能会丢失部分样式。

**word**（单词助手）是一个英语单词学习工具。功能包括：录入单词（自动检索权威词库补全音标、释义和例句）、单词库浏览（卡片形式，带图片墙）、四种练习模式（英译汉四选一、汉译英拼写、选择题、填空题）、每日复习计划（根据你的错题率自动安排每天复习哪些词）、标准真人发音（Web Speech API）、深度词义解析（含中英双解、例句、固定搭配）、词库导出（导出为 Microsoft Word 文档，方便打印）。还带完整的账号注册登录，本地数据按账号分库存。

有两种运行方式：简单模式直接用浏览器打开 `词库管理.html`，完整模式需要解压 `server.zip`、确保装了 Node.js，再双击 `启动单词助手.cmd` 启动本地服务。完整模式支持更完整的多设备数据同步体验。

注意：简单模式下数据存在浏览器 localStorage，换浏览器会丢。词库导入的文件格式需要跟系统导出的格式一致，导入前建议先备份现有词库。Web Speech API 的发音质量取决于你电脑上安装的语音包，部分单词可能读不准。

**card**（老年人应急信息卡）是这份列表里最早的仓库，一个微信小程序。把老人的基本信息、过敏史、慢性病、服用药物、住址、紧急联系人编码成一张专属二维码，老人走失或突发不适时，好心人或医护微信扫码就能看到结构化的应急视图，过敏史这类保命信息红色加粗，还能一键拨打紧急联系人或 120/110/119。二维码在手机上本地生成，可以存相册、打印成实体挂件。

用的时候，装微信开发者工具，clone 仓库后导入项目根目录、填 AppID 编译预览，走公众平台审核就能发布。

注意：所有数据只存在手机本地 `wx.setStorageSync`，不上传任何服务器，生成二维码全程离线——这是设计底线，别指望云端找回，手机丢了数据就没了，所以做好物理打印备份。二维码生成引擎是纯 JS 实现的（`utils/qrcode.js`），没有第三方依赖，但也意味着数据量大时编码密度会变高，信息尽量精简。

## 桌面效率工具

**cmchen-desktopbox**（DeskBasket）是一个 Windows 桌面整理程序：把桌面上散落的文件、快捷方式、文件夹一键按类收进几个"文件夹筐"，屏幕底部再放一条常用软件 Dock，Dock 上还顺手带实时天气。Electron 43 + 原生 JavaScript，没有前端框架，纯逻辑全部拆成不依赖 Electron 的模块直接单测，目前 157 条测试。

先把文件怎么被对待说清楚，因为这是最容易被误解的地方：**每个筐就是磁盘上一个真实文件夹**（默认 `E:\文件筐\<筐名>\`，设置里可改），加进筐的文件会真的移进去，从此归筐所有。但程序自己不删任何东西——Delete 键和右键删除都走系统回收站，随时可恢复；从清单里去掉或删除筐只动清单，磁盘上的文件原样留着。三个例外规则是被 Dock 或别的筐引用着的文件只复制不移动（搬走会把那边弄坏）；跨盘移动先复制、逐层校验名字与大小，一致之后才删源文件，校验不过就原样保留并把原因写进日志；源文件被占用也一样，副本已在筐里、原文件留着并说明。

「一键整理桌面」是它最常用的入口：扫描桌面 → 按扩展名分类（快捷方式、文档、图片、媒体、程序与安装包、其他）→ 预览窗逐类勾选，每类都告诉你目标筐、文件清单、以及为什么有些文件不会动 → 你确认了才动手。规则刻意克制：一类凑够 2 个才单独建筐、一次最多新建 4 个、已有同名筐直接复用、文件夹保持原位。整理完可以一键撤销原路搬回。Dock 有自动收起（碰一下底边滑出来）和常驻两种模式，`F9` 全局热键随时唤出。筐弹窗里空格是 QuickLook 预览（图片直看、文本读前 400KB、音视频直接播），按住拖动换显示顺序，拖出弹窗是移出到落点，拖文件进来是移进筐。筐图标自带 2×2 叠放预览，不开弹窗就知道筐里装了什么。

用的时候，推荐下 `DeskBasket-Setup-x.x.x.exe` 安装包装进当前用户目录，不需要管理员；想绿色运行就双击 `启动DeskBasket.cmd`，已经在跑会明说、缺依赖会指路、起不来会打出日志尾部。源码开发是 Windows 10/11 + Node.js，`npm install` 后 `npm start` 进托盘，`npm test` 跑单测，`npm run dist` 打 NSIS 安装包。

注意：联网只有天气一处（Open-Meteo 免费免 Key，城市留空时多一次 `ipwho.is` 定位），不发送任何本机信息；主进程落盘只有三处——`%APPDATA%\DeskBasket\settings.json`、图标缓存、筐文件夹，此外启动器会向 `%TEMP%` 追加两份日志，删掉整个 settings.json 等于恢复出厂。第一次打开筐稍慢是因为图标第一次要从系统取，取过就缓存了。改「磨砂模式」要重开弹窗才生效，因为窗口材质在创建时就定了。Dock 待在桌面图标那一层，切到别的应用就看不见了，这是特性不是 bug，想让它总是够得着就设成「自动收起」。

**cmchen-clock**（DesktopClock）是一个跨平台桌面时钟，Python + PySide6 写的。像壁纸一样贴在桌面上、被打开的窗口自动遮挡，也可以置顶或当普通窗口用。字体可以从系统字体下拉选、也可以加载 ttf/otf/ttc 文件，字号 8–200、任意颜色、不透明度 10%–100% 全可调，设置面板里实时预览。屏幕位置九宫格一键摆放，也能输精确坐标，还能勾「锁定位置」防误拖。托盘常驻，左键单击隐藏/唤回；每秒整点对齐刷新，几乎不占 CPU。

它最实用的一条是换屏自动纠偏：识别到显示器尺寸变化（外接屏插拔、分辨率或缩放调整、换回笔记本内置屏）后 0.3 秒内自动切回合适的预设位置，不会偏移到屏外或错位。两块屏幕分辨率完全相同也能纠偏——按预设逐像素校验实际位置，并侦测系统挪窗、跨屏字号和 DPI 尺寸变化，纠偏后还会自校验至多 3 轮等系统落定。

双击打包好的 exe 就能跑，或者 `python main.py`；Release 里还提供了 `DesktopClock-Setup.exe` 安装版，装到当前用户目录免管理员，在系统「已安装的应用」里可见可卸载。开机自启在设置面板或右键菜单勾一下就行（Windows 写用户注册表 Run 键、macOS 用 LaunchAgents、Linux 用 XDG Autostart，都是当前用户作用域，随时可取消）。设置和窗口位置记在 `~/.desktop-clock/settings.json`。

注意：运行时依赖只有 PySide6-Essentials 一个包，但打包后的单文件 exe 约 36 MB，别嫌大，Qt 就这个价。Linux 下 Wayland 会话里"固定在桌面"受系统限制，会自动降级成普通窗口行为，想要桌面模式得用 X11。
