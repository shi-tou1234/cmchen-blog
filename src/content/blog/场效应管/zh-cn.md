## 一、场效应管概述

### 1.1 什么是场效应管

**1. 定义**

场效应管（Field Effect Transistors, FET）是利用**电场效应**来控制电流的一种半导体器件，属于**电压控制器件**。由于它仅靠**多数载流子**参与导电，又称为**单极型晶体管**。

:::note
与三极管对比记忆：三极管（BJT）由基极电流控制集电极电流，是**电流控制器件**，多子与少子都参与导电，是**双极型**器件；场效应管由栅源电压产生的电场控制漏极电流，是**电压控制器件**，只有多子导电，是**单极型**器件。
:::

**2. 场效应管的特点**

- 输入阻抗高
- 温度稳定性好
- 低噪声
- 易集成化

**3. 分类**

场效应管按结构分为两大类：**结型**（JFET）和**绝缘栅型**（MOS 管），每一类又按沟道分为 N 沟道和 P 沟道两种。

## 二、结型场效应管（JFET）

### 2.1 结构与符号

结型场效应管有 N 沟道和 P 沟道两种类型。

> **电路描述（N 沟道 JFET）**：在一块 N 型半导体的两侧制作两个**高掺杂的 P 区**，并将它们连接在一起引出一个电极，称为**栅极 G**（Gate）；N 型半导体的两端各引出一个电极，一个称为**漏极 D**（Drain），一个称为**源极 S**（Source）。P 区与 N 区交界面形成**耗尽层**，漏极和源极之间的非耗尽层区域称为**导电沟道**。

**符号规则**：符号中箭头指向为 **PN 结正偏的方向**（N 沟道管箭头指向沟道内侧，P 沟道管箭头指向沟道外侧）。

### 2.2 工作原理

理解 JFET 只需要抓住三个关键量：

1. 栅源电压 $u_{GS}$ **决定沟道的宽窄**；
2. 漏源电压 $u_{DS}$ **决定耗尽层的楔形程度**；
3. $u_{DS}$、$u_{GS}$ 同时作用，决定了管子的最终状态。

**1. 先只看 $u_{GS}$（令 $u_{DS}=0$）：沟道的宽窄**

- 当 $u_{DS}=0$ 且 $u_{GS}=0$ 时，耗尽层很窄，导电沟道**最宽**；
- 当 $|u_{GS}|$ 增大时，两侧耗尽层加宽，导电沟道**变窄**，沟道电阻增大；
- 当 $|u_{GS}|$ 增大到某一数值时，两侧耗尽层**闭合**，沟道消失，沟道电阻趋于无穷大。此时的 $u_{GS}$ 值称为**夹断电压** $U_{GS(off)}$。

> **注意**：工程上认为当漏极电流 $I_D$ 降到 $1\ \mu\mathrm{A}$（或 $10\ \mu\mathrm{A}$）时，就认为管子夹断了。

**2. 再只看 $u_{DS}$（令 $u_{GS}$ 固定）：沟道的楔形**

若 $u_{DS}>0$，电流 $i_D$ 从漏极流向源极。由于沟道自身有电阻，沿沟道存在压降，使得沟道中各点与栅极之间的电压**不再相等**：靠近漏极一侧的 PN 结反偏电压更大，耗尽层**上强下弱**，于是靠近漏极一边的耗尽层比靠近源极一边宽，**沟道呈楔形**。

若 $U_{GS(off)} < u_{GS} < 0$ 且 $u_{DS}>0$：沟道起始宽度变窄，导电沟道更容易夹断；对同样的漏源电压 $u_{DS}$，漏极电流比 $u_{GS}=0$ 时的值**更小**。

**3. 两者同时作用：预夹断与恒流**

因为栅漏电压满足 $u_{GD}=u_{GS}-u_{DS}$，所以当 $u_{DS}$ 逐渐增大时，$u_{GD}$ 逐渐减小，靠近漏极一边的导电沟道必将随之变窄。按 $u_{GD}$ 与 $U_{GS(off)}$ 的关系分三个阶段：

- 一旦 $u_{DS}$ 的增大使 $u_{GD}=U_{GS(off)}$，漏极一边的耗尽层就会出现夹断，即 $u_{DS}=u_{GS}-U_{GS(off)}$ 时称为**预夹断**；
- 若 $u_{DS}$ 继续增大，则 $u_{GD}<U_{GS(off)}$，耗尽层闭合部分将沿沟道向源极延伸，即**夹断区加长**；
- 因此当 $u_{GD}<U_{GS(off)}$ 后，$u_{DS}$ 增大 $i_D$ 几乎不变，即 $i_D$ 几乎仅仅决定于 $u_{GS}$，表现出 $i_D$ 的**恒流性**和**受控性**。

> **注意**：预夹断不等于夹断。预夹断时只是漏极一端耗尽层刚合拢，沟道中仍留有缝隙，漏流依然存在；只有 $u_{GS}\le U_{GS(off)}$ 使整个沟道消失时，管子才真正截止。

### 2.3 转移特性

转移特性描述当漏源电压 $u_{DS}$ 为常量时，漏极电流 $I_D$ 与栅源电压 $U_{GS}$ 之间的函数关系，即

$$ I_D = f(U_{GS})\Big|_{U_{DS}=C} $$

对 N 沟道 JFET：

1. 当 $U_{GS}=0$ 时，N 沟道最宽，$I_D$ 最大，记作 $I_{DSS}$，称**最大饱和漏电流**；
2. 当 $U_{GS}<0$ 时，两个耗尽层加厚，$I_D$ 随之下降，其特征方程为

$$ I_D = I_{DSS}\left(1-\frac{U_{GS}}{U_{GS(off)}}\right)^2 ,\qquad U_{GS(off)} \le U_{GS} \le 0\mathrm{V} $$

3. 当 $U_{GS}=U_{GS(off)}$ 时，N 沟道被夹断，$I_D\approx 0$，管子截止。

### 2.4 漏极（输出）特性

漏极特性描述 $I_D = f(U_{DS})\big|_{U_{GS}=C}$。漏极特性与 BJT 管的输出特性相似，也分为四个区：

| 区域 | 条件 | 特点 |
| :--- | :--- | :--- |
| 可变电阻区 | 预夹断轨迹左边（$u_{GD}>U_{GS(off)}$） | 曲线近似为不同斜率的直线，沟道电阻受 $u_{GS}$ 控制 |
| 恒流区（饱和区、放大区） | 预夹断之后 | 恒流性：各曲线近似为一组与横轴平行的直线；受控性：栅压对漏流有控制作用 |
| 夹断区 | $u_{GS}<U_{GS(off)}$ | 导电沟道被夹断，$i_D\approx 0$ |
| 击穿区 | $u_{DS}$ 过大 | 漏源电压继续增加使 PN 结所受电场过强，发生雪崩击穿 |

预夹断轨迹是各条曲线上使 $u_{GD}=U_{GS(off)}$ 的点连接而成的虚线，它是可变电阻区与恒流区的分界。利用场效应管作为放大管时，应使其工作在**恒流区**。

**关于恒流性的直观解释**：当 $u_{DS}$ 继续增大时，存在两个相反的因素——电源正极的正电荷在漏极附近对电子吸引力增强，有利于漏流；但在 $u_{DS}$ 强电场的作用下，楔形现象严重，增大了沟道电阻，不利于漏流。两者相互抵消，相当于"饱和"，所以漏流基本不变。

**关于原点附近**：在 $u_{DS}$ 较小范围内，$I_D$ 随 $u_{DS}$ 增大而近似正比增大，沟道电阻的倒数决定了斜率；且曲线过原点，说明**漏极和源极可互换使用**（N 沟道 JFET 结构对称）。

### 2.5 P 沟道结型场效应管

1. 将 N 型衬底换成 P 型，两个高掺杂区换成 N+ 区，引出相应的电极；
2. 导电沟道性质不同，参与导电的载流子不同。

特性曲线的对应关系：

- 转移特性曲线与 N 沟道**关于原点对称**；
- 漏极特性曲线族类似，但栅源电压极性不同：P 沟道管要求 $u_{GS}>0$、$u_{DS}<0$。

#### 例题 1：已知 $I_D$ 反求 $U_{GS}$

**题目**：一个结型场效应管 $I_{DSS}=6\ \mathrm{mA}$，$U_{GS(off)}=-4.5\ \mathrm{V}$，确定 $I_D=3\ \mathrm{mA}$ 时所对应的 $U_{GS}$。

**解：**

由转移特性方程

$$ I_D = I_{DSS}\left(1-\frac{U_{GS}}{U_{GS(off)}}\right)^2 $$

:::derivation
**推导说明（反解 $U_{GS}$）：**

将方程两边同除以 $I_{DSS}$ 再开方：

$$ \sqrt{\frac{I_D}{I_{DSS}}} = \left|1-\frac{U_{GS}}{U_{GS(off)}}\right| $$

解出

$$ U_{GS} = U_{GS(off)}\left(1 \pm \sqrt{\frac{I_D}{I_{DSS}}}\right) $$

N 沟道 JFET 要求 $U_{GS(off)} \le U_{GS} \le 0$，开方后必须**取"−"号**的一支：

$$ U_{GS} = -4.5\left(1-\sqrt{\frac{3}{6}}\right) \approx -1.32\ \mathrm{V} $$
:::

**2. 结论**

$$ U_{GS} \approx -1.32\ \mathrm{V} $$

## 三、绝缘栅场效应管（MOS 管）

### 3.1 从 JFET 到 MOS 管

JFET 有几个先天缺点：

- 直流输入电阻不够高；
- 高温下输入电阻下降；
- 栅压不能加正偏电压（否则 PN 结正偏，栅极电流变大）；
- 高度集成困难。

于是人们把栅极与沟道之间用**绝缘层**隔开，制成绝缘栅场效应管：栅极与源极、栅极与漏极之间均采用 $\mathrm{SiO_2}$ 绝缘层隔离，栅极为金属铝，因此称为 **MOS（Metal-Oxide Semiconductor）管**。

MOS 管的特点：**输入阻抗高、耐高温、易集成、栅源电压可正可负**。

MOS 管分为四种类型：**N 沟道耗尽型管、N 沟道增强型管、P 沟道耗尽型管、P 沟道增强型管**。

### 3.2 N 沟道耗尽型 MOS 管

**1. 结构与符号**

> **电路描述**：在 P 型硅衬底上制作两个高掺杂 N+ 区，分别引出源极 S 和漏极 D；衬底表面覆盖一层 $\mathrm{SiO_2}$ 绝缘层，绝缘层上方的金属铝电极是栅极 G。B 端为衬底引线，**常与源极短接在一起**。

**2. N 沟道的形成（反型层）**

当不加外电场（$u_{GS}=0$）时，在二氧化硅层中**事先掺入的正离子**（带正电荷）由于静电感应，能在 P 型衬底表面处（两个 N+ 区之间）感应出同等数量的负电荷（电子），形成 **N 型导电沟道**（又称**反型层**），把两个 N+ 区连接起来。

:::important
**反型层的形成是 MOS 管能工作的关键。** 不加外电场时 N 沟道就已经存在，这正是**耗尽型**的特点——"自带"沟道。
:::

**3. 外电场对 N 沟道的影响**

| $u_{GS}$ 取值 | 沟道状态 | 漏极电流 |
| :--- | :--- | :--- |
| $u_{GS}=0$ | N 沟道已经存在 | $i_D$ 不为零，仍记以 $I_{DSS}$，但不是最大值 |
| $u_{GS}>0$ | 栅极正电荷使 $\mathrm{SiO_2}$ 中原有正电荷数目增加，感应电子随之增加，沟道变宽、电阻减小 | $i_D$ 成指数规律增加 |
| $u_{GS}<0$ | 负电荷抵消一部分 $\mathrm{SiO_2}$ 中原有正离子，沟道变窄、电阻增加 | $i_D$ 成指数规律减小 |
| $u_{GS}=U_{GS(off)}$ | $\mathrm{SiO_2}$ 层中的正电荷全部被负电源中和，N 沟道中电子全部消失 | 沟道电阻为无穷大，$i_D=0$，管子截止（夹断） |

**4. 与结型管的导电机理对比**

:::note
MOS 管与结型管的**导电机理不同**：结型管是利用**耗尽区的宽窄**控制漏流 $i_D$；MOS 管是利用**感应电荷的多少**改变导电沟道的性质，从而达到控制 $i_D$ 的目的。
:::

### 3.3 N 沟道增强型 MOS 管

**1. 结构与符号**

> **电路描述**：在 P 型衬底上制作两个高掺杂 N+ 区（源极 s、漏极 d），衬底表面覆盖二氧化硅绝缘层（厚度 $t_{ox}$），其上为栅极 g（铝电极）。设沟道长度为 $L$、沟道宽度为 $W$，通常 $W>L$。B 为衬底引线。

**2. 增强型的特点**

在 N 沟道的形成上与耗尽型不同：增强型管子的 N 沟道**只有外加电场 $U_{GS}>0$ 时才能存在**，而当 $U_{GS}=0$ 时，N 沟道就不存在了。

**3. 导电沟道是如何形成的**

令 $U_{DS}=0$、$U_{GS}>0$：

- $U_{GS}$ 较小时，由于外电场作用，垂直方向电场使 P 型衬底中的空穴下移、电子上移，使 P 型衬底上表面有负离子构成的空间电荷（耗尽层）；
- $U_{GS}$ 较大时，更多电子被吸引到栅极下，逐渐形成 N 型薄层（**反型层**）。

即：

- 当 $0<U_{GS}<U_{GS(th)}$ 时，只出现耗尽层，尚无导电沟道；
- 当 $U_{GS}>U_{GS(th)}$ 时，出现 N 型导电沟道。

> **定义（开启电压）**：$U_{GS(th)}$ 是指在 $U_{DS}$ 为常量情况下，使 $i_D$ 大于零所需要的最小 $|u_{GS}|$ 值。

**4. 加上 $U_{DS}$ 之后：三个阶段**

设 $U_{DS}>0$ 且 $U_{GS}>U_{GS(th)}$，以 $u_{GD}=u_{GS}-u_{DS}$ 为线索分三段：

- **$u_{DS}<u_{GS}-U_{GS(th)}$ 时**：因为 $u_{GD}=u_{GS}-u_{DS}>U_{GS(th)}$，漏极附近反型层所需的垂直栅控电场减弱，反型层变薄，沟道变成楔形，但沟道电阻无明显变化，$i_D$ 随 $u_{DS}$ 的增大而增大——可变电阻区；
- **$u_{DS}=u_{GS}-U_{GS(th)}$ 时**：$u_{GD}=U_{GS(th)}$，漏极附近反型层首先消失，恰好出现**预夹断**；
- **$u_{DS}>u_{GS}-U_{GS(th)}$ 时**：继续增大 $u_{DS}$，夹断区朝源极方向延伸，$i_D$ 几乎仅仅受控于 $u_{GS}$，而不随 $u_{DS}$ 变化，趋于饱和——$u_{DS}$ 的增大几乎全部用来克服夹断区的电阻。

### 3.4 特性曲线与电流方程

**1. 输出特性**

增强型 NMOS 管的输出特性上也分为**可变电阻区、饱和区（恒流区）、夹断区、击穿区**四个区，各区分界与 JFET 类似（预夹断轨迹为 $u_{DS}=u_{GS}-U_{GS(th)}$）。

**2. 可变电阻区的电流方程**

当 $U_{DS} \le U_{GS}-U_{GS(th)}$ 时：

$$ i_D = K_n\left[2\left(U_{GS}-U_{GS(th)}\right)U_{DS} - U_{DS}^2\right] $$

其中 $K_n$ 为**电导常数**，单位 $\mathrm{mA/V^2}$：

$$ K_n = \frac{K_n'}{2}\cdot\frac{W}{L} = \frac{\mu_n C_{ox}}{2}\left(\frac{W}{L}\right) $$

式中 $\mu_n$ 为反型层中电子迁移率，$C_{ox}$ 为栅极（与衬底间）氧化层单位面积电容，$K_n'=\mu_n C_{ox}$ 称为本征电导因子。

由于 $U_{DS}$ 较小，可近似为

$$ i_D \approx 2K_n\left(U_{GS}-U_{GS(th)}\right)U_{DS} $$

此时漏源之间相当于一个受 $U_{GS}$ 控制的可变电阻：

$$ r_{dso} = \frac{dU_{DS}}{di_D}\bigg|_{U_{GS}=常数} = \frac{1}{2K_n\left(U_{GS}-U_{GS(th)}\right)} $$

**3. 饱和区（恒流区，又称放大区）的电流方程**

当 $U_{GS}>U_{GS(th)}$ 且 $U_{DS}\ge U_{GS}-U_{GS(th)}$ 时：

$$ i_D = K_n\left(U_{GS}-U_{GS(th)}\right)^2 = I_{DO}\left(\frac{U_{GS}}{U_{GS(th)}}-1\right)^2 $$

其中 $I_{DO}=K_n U_{GS(th)}^2$，是 $U_{GS}=2U_{GS(th)}$ 时的 $i_D$。

**4. 转移特性**

转移特性为 $i_D = f(U_{GS})\big|_{U_{DS}=const}$，代入饱和区方程即可，曲线为一条开口向上的抛物线（平方律），起点在 $U_{GS(th)}$。

**5. 沟道长度调制效应**

- **理想条件**：MOS 管工作于饱和区时，漏极电流与漏源电压无关（曲线平坦）；
- **实际情形**：饱和区输出特性曲线还应考虑漏源电压对沟道长度 $L$ 的调制作用，即固定栅源电压、增加漏源电压时，漏极电流会有所增加，每根曲线向上倾斜。

引入**沟道长度调制参数** $\lambda \approx \dfrac{0.1}{L}\ \mathrm{V^{-1}}$（$L$ 的单位为 $\mu\mathrm{m}$），修正后

$$ i_D = K_n\left(U_{GS}-U_{GS(th)}\right)^2\left(1+\lambda U_{DS}\right) $$

当不考虑沟道调制效应时，$\lambda=0$，曲线是平坦的。

### 3.5 P 沟道增强型 MOS 管（PMOS）

> **电路描述**：在 N 型硅衬底上制作两个 P+ 区作为源极与漏极，其余结构与 NMOS 对称。

1. 导电沟道性质不同；
2. 栅源电压**必须为负值**，漏源电压和漏极电流与 NMOS 相反。

## 四、场效应管的主要参数

### 4.1 直流参数

| 参数 | 定义 | 适用对象 |
| :--- | :--- | :--- |
| 夹断电压 $U_{GS(off)}$ | 在 $U_{DS}$ 为常量情况下，$i_D\approx 0$ 时对应的 $u_{GS}$ 值 | 结型管及耗尽型 MOS 管，约有几伏数量级 |
| 开启电压 $U_{GS(th)}$ | 在 $U_{DS}$ 为常量情况下，使 $i_D$ 大于零所需的最小 $\|u_{GS}\|$ 值 | 增强型 MOS 管 |
| 饱和漏电流 $I_{DSS}$ | 耗尽型管在 $u_{GS}=0$ 情况下进入饱和区后的漏极电流 | 耗尽型管 |
| 直流输入电阻 $R_{GS}$ | 漏源电压为零时，栅源电压与栅极电流的比值 | 结型管约 $10^7\sim10^9\ \Omega$；MOS 管一般可达 $10^{12}\sim10^{15}\ \Omega$ |

### 4.2 交流参数

**1. 输出电阻 $r_{ds}$**

$$ r_{ds} = \frac{\partial U_{DS}}{\partial i_D}\bigg|_{U_{GS}} $$

反映了漏源电压对漏极电流的影响，又叫**漏极内阻**。考虑沟道调制效应时：

$$ r_{ds} = \left[\lambda K_n\left(U_{GS}-U_{GS(th)}\right)^2\right]^{-1} = \frac{1}{\lambda i_D} $$

当不考虑沟道调制效应时，$\lambda=0$，$r_{ds}\to\infty$。

**2. 低频跨导 $g_m$**

表示 $\Delta u_{GS}$ 对 $i_D$ 控制作用的强弱：在管子工作在恒流区且 $u_{DS}$ 为常量的条件下，$i_D$ 的微小变化量 $\Delta i_D$ 与引起它变化的 $\Delta u_{GS}$ 之比，称为**低频跨导**，即

$$ g_m = \frac{\Delta i_D}{\Delta u_{GS}}\bigg|_{U_{DS}=C} $$

数量级为零点几 $\mathrm{mS}$ 到几 $\mathrm{mS}$。$g_m$ 是转移特性曲线上某一点切线的斜率，与切点的位置密切相关。

对增强型 NMOS 管，将饱和区方程对 $U_{GS}$ 求导：

:::derivation
**推导说明（$g_m$ 的两种表达式）：**

由 $i_D = K_n\left(U_{GS}-U_{GS(th)}\right)^2$，对 $U_{GS}$ 求偏导：

$$ g_m = \frac{\partial i_D}{\partial U_{GS}}\bigg|_{U_{DS}} = 2K_n\left(U_{GS}-U_{GS(th)}\right) $$

又因为 $U_{GS}-U_{GS(th)} = \sqrt{i_D/K_n}$，代入上式：

$$ g_m = 2K_n\sqrt{\frac{i_D}{K_n}} = 2\sqrt{K_n i_D} $$
:::

对结型管，由 $i_D = I_{DSS}\left(1-\dfrac{U_{GS}}{U_{GS(off)}}\right)^2$（其中 $K_n = \dfrac{I_{DSS}}{U_{GS(off)}^2}$）可得

$$ g_m = \frac{2I_{DSS}}{|U_{GS(off)}|}\left(1-\frac{U_{GS}}{U_{GS(off)}}\right) $$

### 4.3 极限参数

- **最大漏极电流 $I_{DM}$**：管子正常工作时漏极电流的上限值；
- **击穿电压 $U_{(BR)DS}$**：在漏极特性中使 $i_D$ 开始剧增的 $U_{DS}$ 值；
- **击穿电压 $U_{(BR)GS}$**：对结型管，使反向饱和电流开始剧增时所对应的 $U_{GS}$ 值；对 MOS 管，使 $\mathrm{SiO_2}$ 绝缘层击穿的 $U_{GS}$ 值。

### 4.4 微变等效电路及其参数（小信号）

- **低频模型**：栅源之间开路（输入电阻极大），漏源之间是受控电流源 $I_d = g_m \dot{U}_{gs}$ 与输出电阻 $r_{ds}$ 并联。$r_{ds}$ 在恒流区数值很大，常作**开路**处理；
- **高频模型**：在低频模型基础上增加极间电容 $C_{gs}$、$C_{gd}$、$C_{ds}$，分析高频响应时不可忽略。

## 五、场效应管与双极型三极管的比较

| 序号 | 对比项 | 场效应管（FET） | 双极型三极管（BJT） |
| :--- | :--- | :--- | :--- |
| 1 | 控制类型 | **电压控制元件** | **电流控制元件** |
| 2 | 载流子 | 仅**多子**参与导电（单极型） | 既利用多子又利用**少子**（双极型） |
| 3 | 噪声 | 噪声系数比三极管小 | 相对较大 |
| 4 | 电极互换性 | 有些管子 D、S 可互换，栅极电压可正可负，灵活性强 | C、E 不能互换 |
| 5 | 工作条件 | 能在很小的电流、很低的电压条件下工作 | 工作电流电压相对较大 |
| 6 | 工作频率 | 工作频率较低，不适合高频运用 | 高频特性好 |

逐条展开工程含义：

1. **选用原则**：在向信号源基本不取电流的情况下，应该用场效应管；在信号电压较弱但又允许取一定电流的情况下，应选用双极型三极管。
2. **温度稳定性**：场效应管只靠多子导电，在环境条件变化比较剧烈的情况下，采用场效应管比较合适。而且场效应管有一个**零温度系数工作点**，即当栅极电压在某一合适的数值时，$i_D$ 不受温度变化的影响。
3. **低噪声**：在低噪声放大器的前级，常选用场效应管。
4. **小功率与集成**：场效应管适用于作为小功率无触点开关和由电压控制的可变电阻，制造工艺便于集成化，在电子设备中得到广泛应用。
5. **防栅穿**：绝缘栅场效应管容易被感应电压击穿，称为**栅穿**。使用和保存时应注意防栅穿：保存时将各电极短接在一起；焊接时电烙铁要有良好的接地线，或断电后利用余热焊接。

:::tip[一句话总结]
**没有完美的器件，只有最合适的选择。** FET 和 BJT 在不同应用场景中需要权衡多种因素选择。
:::

## 六、总结与注意事项

### 6.1 场效应管家族一览

场效应管均含有两个 PN 结（结型）或等效的栅控结构，按"结构 + 沟道 + 工作方式"可分为六种管型：

| 类型 | 电压极性要求 |
| :--- | :--- |
| 结型 N 沟道 | $u_{GS}<0$，$u_{DS}>0$ |
| 结型 P 沟道 | $u_{GS}>0$，$u_{DS}<0$ |
| 增强型 N 沟道 | $u_{GS}>0$，$u_{DS}>0$ |
| 增强型 P 沟道 | $u_{GS}<0$，$u_{DS}<0$ |
| 耗尽型 N 沟道 | $u_{GS}$ 极性任意，$u_{DS}>0$ |
| 耗尽型 P 沟道 | $u_{GS}$ 极性任意，$u_{DS}<0$ |

场效应管具有输入电阻高、温度稳定性好、低噪声、便于集成、灵活性强等特点。它也有两族特性曲线，分别为**转移特性**和**漏极特性**；漏极特性中的饱和区表现出受控性与恒流性，其控制量为栅压、受控量为漏流，因此它们是**压控器件**。描述放大作用的参数是**低频跨导** $g_m$。

### 6.2 核心公式速查

| 概念 | 公式 | 说明 |
| :--- | :--- | :--- |
| JFET / 耗尽型转移特性 | $I_D = I_{DSS}\left(1-\dfrac{U_{GS}}{U_{GS(off)}}\right)^2$ | $U_{GS(off)} \le U_{GS} \le 0$（N 沟道） |
| 增强型饱和区电流 | $i_D = K_n\left(U_{GS}-U_{GS(th)}\right)^2$ | $U_{GS}>U_{GS(th)}$ 且 $U_{DS}\ge U_{GS}-U_{GS(th)}$ |
| $I_{DO}$ 定义 | $I_{DO} = K_n U_{GS(th)}^2$ | $U_{GS}=2U_{GS(th)}$ 时的 $i_D$ |
| 可变电阻区电流 | $i_D = K_n[2(U_{GS}-U_{GS(th)})U_{DS}-U_{DS}^2]$ | $U_{DS}\le U_{GS}-U_{GS(th)}$ |
| 可变电阻近似 | $i_D \approx 2K_n(U_{GS}-U_{GS(th)})U_{DS}$ | $U_{DS}$ 较小时 |
| 压控电阻 | $r_{dso} = \dfrac{1}{2K_n(U_{GS}-U_{GS(th)})}$ | 受 $U_{GS}$ 控制的可变电阻 |
| 沟道长度调制 | $i_D = K_n(U_{GS}-U_{GS(th)})^2(1+\lambda U_{DS})$ | $\lambda\approx 0.1/L\ \mathrm{V^{-1}}$ |
| 跨导（增强型） | $g_m = 2K_n(U_{GS}-U_{GS(th)}) = 2\sqrt{K_n i_D}$ | 恒流区，$u_{DS}$ 为常量 |
| 输出电阻 | $r_{ds} = 1/(\lambda i_D)$ | 考虑调制效应；$\lambda=0$ 时 $r_{ds}\to\infty$ |

### 6.3 易错点提醒

1. **夹断电压与开启电压不要混用**：$U_{GS(off)}$ 适用于结型管和耗尽型 MOS 管；$U_{GS(th)}$ 适用于增强型 MOS 管。
2. **预夹断不是夹断**：预夹断是漏端耗尽层刚合拢，是可变电阻区与恒流区的分界，管子仍在导电；只有 $u_{GS}\le U_{GS(off)}$（结型/耗尽型）或 $u_{GS}<U_{GS(th)}$（增强型）使沟道整体消失时管子才截止。
3. **耗尽型栅压可正可负，结型不能正偏**：N 沟道耗尽型 MOS 管的 $u_{GS}$ 极性任意（$U_{GS(off)}\le u_{GS}$）；而 N 沟道结型管必须保证 $u_{GS}\le 0$，否则 PN 结正偏。
4. **"饱和区"名称的陷阱**：MOS 管的饱和区（恒流区）对应 BJT 的**放大区**，而不是 BJT 的饱和区。
5. **防栅穿是 MOS 管的必修课**：手上的静电就可能击穿 $\mathrm{SiO_2}$ 绝缘层，存放时三个电极要短接，焊接时烙铁要接地或断电用余热。

### 6.4 解题要点

- **判断工作区**（增强型 NMOS）：先看是否满足 $u_{GS}>U_{GS(th)}$（否则夹断区截止）；再比较 $u_{DS}$ 与 $u_{GS}-U_{GS(th)}$：小于则在可变电阻区，大于等于则在饱和区。
- **已知 $I_D$ 反求 $U_{GS}$**：开平方后正负两支根中，取落在 $[U_{GS(off)},\,0]$（N 沟道结型/耗尽型）内的那一支，参见例题 1。
- **求 $g_m$**：给了 $K_n$ 与 $U_{GS}$ 用 $g_m = 2K_n(U_{GS}-U_{GS(th)})$；给了静态电流 $i_D$ 用 $g_m = 2\sqrt{K_n i_D}$，两者等价。
- **JFET 题目默认套转移特性方程**：$I_D = I_{DSS}\left(1-\frac{U_{GS}}{U_{GS(off)}}\right)^2$ 是结型管一切计算的核心。

:::tip[学习建议]
记不住六个管型的极性时，只记两条主线：**结型靠耗尽层"挤"沟道，所以栅极必须反偏（N 沟道 $u_{GS}<0$）**；**MOS 靠感应电荷"生"沟道，增强型必须"充"出反型层（N 沟道 $u_{GS}>0$），耗尽型因为自带沟道所以极性任意**。P 沟道全部反号即可。
:::
