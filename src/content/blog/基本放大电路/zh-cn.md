## 一、放大的概念与放大电路模型

### 1.1 什么是放大

**1. 概念**

将微弱的电信号通过放大电路放大到具有足够大的功率去推动负载，就是**放大**。

**2. 放大的本质**

放大的本质是**能量的控制和转换**：在输入信号作用下，通过放大电路将直流电源的能量转换成负载所获得的能量，使负载从电源获得的能量大于信号源所提供的能量。

:::note
放大的对象是**变化量**，放大器件只起"能量控制"作用——三极管用基极小电流控制集电极大电流，场效应管用栅极电压控制漏极电流，真正的能量来自直流电源。
:::

**3. 放大的基本要求**

**不失真**——只有在不失真的情况下放大才有意义。

### 1.2 放大电路的模型（二端口网络）

任何放大电路均可看成为**二端口网络**：

> **电路描述**：左端是输入回路——信号源 $v_s$ 串内阻 $R_s$，加到放大电路输入端口上产生输入电压 $v_i$ 和输入电流 $i_i$；右端是输出回路——放大电路向负载 $R_L$ 提供输出电压 $v_o$ 和输出电流 $i_o$。

按输出量与输入量的不同组合，增益有四种形式：

| 增益名称 | 定义 | 量纲 |
| :--- | :--- | :--- |
| 电压增益 $A_v$ | $A_v = \dfrac{v_o}{v_i}$ | 无量纲 |
| 电流增益 $A_i$ | $A_i = \dfrac{i_o}{i_i}$ | 无量纲 |
| 互阻增益 $A_r$ | $A_r = \dfrac{v_o}{i_i}$ | $\Omega$ |
| 互导增益 $A_g$ | $A_g = \dfrac{i_o}{v_i}$ | $\mathrm{S}$ |

根据输入信号的条件和对输出信号的要求，放大电路有三种基本模型：

1. **电压放大模型**：指标是**负载开路时电压增益** $A_{vo}$，含输入电阻 $R_i$ 与输出电阻 $R_o$；
2. **电流放大模型**：指标是**负载短路时电流增益** $A_{is}$；
3. **隔离放大电路模型**：输入输出回路**没有公共端**，起隔离与缓冲作用。

## 二、放大电路的性能指标

### 2.1 放大倍数（增益）

增益是**直接衡量放大电路放大能力的重要指标**。电压放大倍数为输出电压 $U_o$ 与输入电压 $U_i$ 之比：

$$ A_u = \frac{U_o}{U_i} $$

其中 $U_o$、$U_i$ 都是**有效值**。

> **注意**：实测放大倍数时，应使用示波器观察输出端的波形，**只有在不失真的情况下，测试数据才有意义**，其它指标也如此。

### 2.2 输入电阻

输入电阻 $r_i$ 是从放大电路**输入端看进去的交流等效电阻**，定义为输入电压有效值 $U_i$ 和输入电流有效值 $I_i$ 之比：

$$ r_i = \frac{U_i}{I_i} $$

放大电路接到信号源上，相当于信号源带了一个负载。信号源内阻 $R_s$ 上的分压就是"衰减"：

$$ U_i = \frac{r_i}{R_s + r_i}U_s $$

- **电压放大模型**：想要减小对信号源的衰减，即让信号电压 $U_s$ 损失越小越好，则希望 $r_i$ **越大越好**——$r_i$ 越大，表明放大电路所得到的输入电压 $U_i$ 越接近信号源电压 $U_s$；
- **电流放大模型**：输入电流 $I_i = I_s\dfrac{R_s}{R_s+r_i}$，要想减小对信号源的衰减，则希望 $r_i \ll R_s$。

### 2.3 输出电阻

输出电阻 $r_o$ 就是**负载开路时从放大电路输出端看进去的交流等效电阻**：

$$ r_o = \frac{U_o}{I_o}\bigg|_{U_S=0,\ R_L=\infty} $$

放大电路中负载大小可变，而负载的大小会影响电压增益的大小。将放大电路输出等效成有内阻的电压源（空载电压 $U_o'$ 串输出电阻 $r_o$），由输出回路得

$$ U_o = U_o'\frac{R_L}{r_o + R_L} $$

其中 $U_o' = A_{vo}U_i$，则电压增益为

$$ A_u = \frac{U_o}{U_i} = A_{vo}\frac{R_L}{r_o + R_L} $$

**负载变小，电压增益变小。** 想要减小负载变动对放大电路的影响，希望输出电阻越小越好——输出电阻越小，负载电阻变化时输出电压的变化越小，称为放大电路的**带负载能力越强**。

:::note
对**电流放大模型**，结论则相反：希望输出电阻越大越好，输出电流才不随负载变化。
:::

**输出电阻的实验测定法**

测空载时输出电压有效值 $U_o'$，再测带负载 $R_L$ 时的输出电压有效值 $U_o$，由

$$ U_o = U_o'\frac{R_L}{r_o + R_L} $$

:::derivation
**推导说明（反解 $R_o$）：**

将上式变形：

$$ \frac{U_o'}{U_o} = \frac{r_o + R_L}{R_L} $$

解出

$$ R_o = \left(\frac{U_o'}{U_o} - 1\right)R_L $$
:::

### 2.4 通频带

通频带衡量放大电路**对不同频率信号的放大能力**。放大倍数的数值与信号频率的关系曲线，称为**幅频特性曲线**，$A_{um}$ 为中频放大倍数的数值。

- 在信号频率下降到一定程度时，放大倍数的数值明显下降，使放大倍数的数值等于 $0.707|A_{um}|$ 的频率称为**下限截止频率** $f_L$；
- 在信号频率上升到一定程度时，放大倍数的数值也将减小，使放大倍数的数值等于 $0.707|A_{um}|$ 的频率称为**上限截止频率** $f_H$；
- $f_H$ 与 $f_L$ 之间形成的频带称为放大电路的**通频带**：

$$ f_{bw} = f_H - f_L $$

通频带越宽，表明放大电路对不同频率信号的适应能力越强。

### 2.5 非线性失真系数

**非线性失真**是由元器件非线性特性引起的失真。输出波形中的谐波成分总量与基波成分之比称为**非线性失真系数** $D$。设基波幅值为 $A_1$、谐波幅值为 $A_2, A_3, \dots$，则

$$ D = \sqrt{\left(\frac{A_2}{A_1}\right)^2 + \left(\frac{A_3}{A_1}\right)^2 + \cdots} $$

### 2.6 最大不失真输出电压

**最大不失真输出电压** $U_{om}$：当输入电压再增大就会使输出波形产生非线性失真时的输出电压。

### 2.7 最大输出功率与效率

- **最大输出功率** $P_{om}$：在输出信号不失真的情况下，负载上能够获得的最大功率。此时，输出电压达到最大不失真输出电压；
- **效率** $\eta$：直流电源能量的利用率。设电源消耗的功率为 $P_V$，则效率等于最大输出功率 $P_{om}$ 与 $P_V$ 之比：

$$ \eta = \frac{P_{om}}{P_V} $$

:::tip[工程上的启示]
放大电路的各项性能指标直接影响各类实际应用。工程设计应当根据实际具体需求进行设计和选取，**不能盲目追求各项指标的最优化和极致化**；需要权衡成本与性能，考虑安全性、可靠性、隐私保护与环境保护等因素。
:::

## 三、放大电路的组成原则与共射放大电路

### 3.1 组成原则

为了实现**不失真地放大交流信号**，放大电路必须同时满足以下四项原则：

1. 必须根据所使用放大管的类型**提供直流电源**，以便使放大管处于放大状态，并作为输出的能源；
2. **输入回路**应使交流信号电压能加到管子上，使产生交流电流；
3. **输出回路**应使输出电流尽可能多地流到负载上，减少其他分流；
4. 在没有外加信号时使放大管有一个合适的**静态工作点**，即设置合理的静态工作点。

### 3.2 以 NPN 管共射放大电路为例

> **电路描述**：NPN 三极管 T 的发射极 E 接地；基极 B 经偏置电阻 $R_b$ 接基极电源 $V_{BB}$，输入信号 $u_i$ 经耦合电容 $C_1$ 接到基极；集电极 C 经集电极负载电阻 $R_c$ 接集电极电源 $V_{CC}$，再经耦合电容 $C_2$ 引出输出电压 $u_o$ 到负载 $R_L$。

对照四条组成原则：

1. **电源极性必须使放大管处于放大状态**：e 结正偏、c 结反偏；
2. 输入回路应使交流信号电压能加到管子上，使产生交流电流 $i_b$；
3. 输出回路应使输出电流 $i_c$ 尽可能多地流到负载上，减少其他分流；
4. 必须在没有外加信号时使放大管有一个合适的静态工作点 Q，称为设置合理的静态工作点。

### 3.3 各元件的作用

| 元件 | 作用 |
| :--- | :--- |
| 三极管 V | 放大器件，能量控制元件 |
| $V_{BB}$ | 提供偏置电流，保证 e 结正偏 |
| $R_b$ | 偏置电阻，防止输入信号短路 |
| $V_{CC}$ | 使 $U_c > U_b > U_e$，c 结反偏，同时作为负载的能源 |
| $R_c$ | 集电极负载电阻，将 $i_c$ 转换成电压输出 |
| $C_1$、$C_2$ | 隔直耦合电容 |
| $R_L$ | 负载电阻 |

### 3.4 习惯画法与两种单电源电路

将 $V_{BB}$ 的作用合并到 $V_{CC}$ 上（适当加大 $R_b$），可得**单电源供电**的习惯画法——这是最常用的共射放大电路画法。

单电源供电有两种实现：

1. **直接耦合共射放大电路**：基极偏置由 $R_{b1}$、$R_{b2}$ 分压获得，输入信号直接叠加到基极。静态时 $U_{BEQ} = U_{Rb1}$；动态时 $V_{CC}$ 和 $u_i$ 同时作用于晶体管的输入回路。缺点：**有交流损失，有直流成分**（输出中含有直流分量）；
2. **阻容耦合共射放大电路**：输入输出都经电容耦合。静态时 $U_{C1} = U_{BEQ}$，$U_{C2} = U_{CEQ}$（电容被充上静态电压）；动态时 $u_{BE} = u_i + U_{BEQ}$，信号驮载在静态之上，**负载上只有交流信号**。注意**耦合电容的容量应足够大**（对交流信号近似短路）。

### 3.5 四个"不能正常放大"的反例

判断一个电路能否正常放大，就用 3.1 节的四条原则去套：

1. **e 结未正偏**——不能正常放大；
2. **无法产生偏置电流，没有合理工作点**——不能正常放大；
3. **信号无法加载到三极管上**（输入回路被电容隔断或对地短路）——不能正常放大；
4. **信号无法输出**（输出回路被隔断）——不能正常放大。

## 四、静态工作点与动态工作过程

### 4.1 静态工作点 Q

当 $u_i = 0$ 时，晶体管的基极电流 $I_B$、集电极电流 $I_C$、b-e 间电压 $U_{BE}$、管压降 $U_{CE}$ 称为放大电路的**静态工作点 Q**，常将这四个物理量记作 $I_{BQ}$、$I_{CQ}$、$U_{BEQ}$、$U_{CEQ}$。

由三极管的输入特性可知，$U_{BE}$ 的变化范围很小，可以近似地认为：

- 硅管的 $U_{BEQ} = (0.6 \sim 0.8)\ \mathrm{V}$；
- 锗管的 $U_{BEQ} = (0.1 \sim 0.3)\ \mathrm{V}$。

$U_{BEQ}$ 作为已知量处理，只需估算出 $U_{CEQ}$、$I_{BQ}$ 及 $I_{CQ}$，那么静态工作点就是确定的了。

> **重要**：静态工作点（Q 点）不仅影响电路是否会产生失真，而且影响着放大电路几乎所有的动态参数。

### 4.2 动态信号的作用过程

当 $u_i \neq 0$ 时，整个电路是"直流叠交流"：

1. 当 $u_i \neq 0$ 时，基极电流是在原来直流分量 $I_{BQ}$ 的基础上叠加一个正弦交流电流 $i_b$，因而基极总电流 $i_B = I_{BQ} + i_b$；
2. 根据晶体管基极电流对集电极电流的控制作用，集电极电流会在直流分量 $I_{CQ}$ 的基础上产生一个正弦交流电流 $i_c$，且 $i_c = \beta i_b$，集电极总电流 $i_C = I_{CQ} + \beta i_b$；
3. 管压降是在直流分量 $U_{CEQ}$ 的基础上叠加一个与 $i_c$ 变化方向相反的交变电压 $u_{ce}$，管压降总量 $u_{CE} = U_{CEQ} + u_{ce}$；
4. 将管压降中的直流分量 $U_{CEQ}$ 去掉（隔直电容），得到一个与输入电压 $u_i$ **相位相反**且放大了的交流电压 $u_o$。

动态信号传播路径概括为：

$$ \Delta u_I \rightarrow i_b \rightarrow i_c \rightarrow \Delta u_{R_c} \rightarrow \Delta u_{CE}\ (u_o) $$

### 4.3 结论

对于基本共射放大电路，**只有设置合适的静态工作点，使交流信号驮载在直流分量之上**，以保证晶体管在输入信号的整个周期内始终工作在放大状态，输出电压波形才不会产生非线性失真。

## 五、直流通路与交流通路

### 5.1 基本概念

一般情况下，在放大电路中，直流量（静态电流与电压）和交流信号（动态电流与电压）**总是共存的**。为了研究问题方便起见，常将它们分开考虑，分成直流通路和交流通路。

| 概念 | 含义 |
| :--- | :--- |
| 静态 | 不加输入信号（$U_i=0$）时电路所处的状态，对应静态工作点 Q → $I_{BQ}$、$U_{BEQ}$、$I_{CQ}$、$U_{CEQ}$ |
| 直流通路 | 直流电流通过的路径，用于研究静态工作点 |
| 动态 | 有外加输入信号（$U_i \neq 0$）时电路所处的状态 |
| 交流通路 | 交流电流通过的路径，用于研究动态参数 |

放大电路的两种基本分析方法（外加图解法共三种）：

1. **静态估算法（公式法）**——求静态工作点 $Q \to (I_{BQ}, U_{BEQ}, I_{CQ}, U_{CEQ})$，利用**直流通路**；
2. **h 参数微变等效电路法**——求放大电路性能指标 $A_u$、$r_i$、$r_o$，利用**交流通路**；
3. **图解法**——分析静态工作点 Q、波形分析，求最大不失真输出电压 $U_{om}$，利用输出伏安特性曲线。

### 5.2 直流通路及其画法

**直流通路**：在直流电源作用下直流电流流经的通路，也就是静态电流流经的通路，用于研究静态工作点。

**画法原则**：

1. **电容视为"开路"**；
2. **电感线圈视为短路**（即忽略线圈电阻）。

> **电路描述（共射电路的直流通路）**：电容 $C_1$、$C_2$ 开路后，$R_L$ 与输入信号源一起被断开，电路只剩 $V_{CC}$ 经 $R_b$ 到基极、经 $R_C$ 到集电极两条直流通路。

从输入回路列 KVL：

:::derivation
**推导说明（静态估算三公式）：**

输入回路：$V_{CC} = I_B R_b + U_{BE}$，解出

$$ I_{BQ} = \frac{V_{CC} - U_{BEQ}}{R_b} $$

由三极管的电流控制关系：

$$ I_{CQ} = \beta I_{BQ} $$

输出回路：$V_{CC} = U_{CE} + I_C R_C$，解出

$$ U_{CEQ} = V_{CC} - I_{CQ}R_C $$
:::

#### 例题 1：估算共射放大电路的静态工作点

**题目**：NPN 硅管共射电路，$V_{CC}=12\ \mathrm{V}$，$R_c=3\ \mathrm{k\Omega}$，$R_b=300\ \mathrm{k\Omega}$，$R_L=3\ \mathrm{k\Omega}$，$\beta=50$，估算静态工作点。

**解：**

**1. 画直流通路**：$C_1$、$C_2$ 开路，$R_L$ 断开，只保留 $V_{CC}$、$R_b$、$R_c$ 与三极管。

**2. 基极电流**

$$ I_{BQ} = \frac{V_{CC} - U_{BEQ}}{R_b} = \frac{12 - 0.7}{300\ \mathrm{k\Omega}} \approx 37.7\ \mu\mathrm{A} \approx 40\ \mu\mathrm{A} $$

**3. 集电极电流**（工程估算中 $I_{BQ}$ 常取整为 $40\ \mu\mathrm{A}$）

$$ I_{CQ} \approx \beta I_{BQ} = 50 \times 0.04\ \mathrm{mA} = 2\ \mathrm{mA} $$

**4. 管压降**

$$ U_{CEQ} = V_{CC} - I_{CQ}R_c = 12 - 2 \times 3 = 6\ \mathrm{V} $$

**5. 结论**：$Q$ 点为 $I_{BQ}\approx 40\ \mu\mathrm{A}$，$I_{CQ}\approx 2\ \mathrm{mA}$，$U_{CEQ}=6\ \mathrm{V}$。

#### 例题 2：独立基极电源的静态估算

**题目**：画出直流通路并估算静态工作点。已知集电极接 $+10\ \mathrm{V}$，集电极电阻 $3\ \mathrm{k\Omega}$；基极经 $15\ \mathrm{k\Omega}$ 电阻接 $1.2\ \mathrm{V}$ 电源，$U_{BEQ}=0.7\ \mathrm{V}$，$\beta=60$。

**解：**

**1. 画直流通路**：电容开路后，基极回路为 $1.2\ \mathrm{V}$ 电源串 $15\ \mathrm{k\Omega}$ 接 b；集电极回路为 $+10\ \mathrm{V}$ 串 $3\ \mathrm{k\Omega}$ 接 c。

**2. 逐级计算**

$$ I_{BQ} = \frac{1.2 - 0.7}{15\ \mathrm{k\Omega}} \approx 33\ \mu\mathrm{A} $$

$$ I_{CQ} = 60 \times 0.033\ \mathrm{mA} \approx 1.98\ \mathrm{mA} $$

$$ U_{CEQ} = 10 - 1.98 \times 3 \approx 4.06\ \mathrm{V} $$

:::note
思考：**PNP 管怎么办？** 电源极性相反、电流方向相反，但静态估算三公式的形式完全一样，只需注意电压取值的符号约定。
:::

### 5.3 交流通路及其画法

**交流通路**：输入信号作用下交流信号流经的通路，用于研究动态参数。

**画法原则**：

1. **电容值大的电容（如耦合电容）视为短路**；
2. **无内阻的直流电源视为短路**。

> **电路描述（共射电路的交流通路）**：$V_{CC}$ 对地短路后，$R_c$ 上端接"地"；$C_1$、$C_2$ 短路后，输入电压 $u_i$ 直接加在基极（与 $R_b$ 并联），输出电压 $u_o$ 从集电极取出——$R_c$ 与 $R_L$ 并联构成集电极交流负载。

## 六、总结与注意事项

### 6.1 核心公式速查

| 概念 | 公式 | 说明 |
| :--- | :--- | :--- |
| 电压放大倍数 | $A_u = \dfrac{U_o}{U_i}$ | $U_o$、$U_i$ 均为有效值，须在不失真前提下测 |
| 带源衰减 | $U_i = \dfrac{r_i}{R_s+r_i}U_s$ | 电压放大希望 $r_i$ 大 |
| 负载压降 | $A_u = A_{vo}\dfrac{R_L}{r_o+R_L}$ | 电压放大希望 $r_o$ 小 |
| 输出电阻实测 | $R_o = \left(\dfrac{U_o'}{U_o}-1\right)R_L$ | $U_o'$ 空载、$U_o$ 带载 |
| 通频带 | $f_{bw} = f_H - f_L$ | 截止于 $0.707\|A_{um}\|$ |
| 非线性失真系数 | $D = \sqrt{(A_2/A_1)^2 + (A_3/A_1)^2 + \cdots}$ | 谐波总量与基波之比 |
| 效率 | $\eta = P_{om}/P_V$ | 最大不失真功率比电源功耗 |
| 基极静态电流 | $I_{BQ} = \dfrac{V_{CC}-U_{BEQ}}{R_b}$ | 直流通路，硅管取 $U_{BEQ}\approx 0.7\ \mathrm{V}$ |
| 集电极静态电流 | $I_{CQ} = \beta I_{BQ}$ | 电流控制关系 |
| 管压降 | $U_{CEQ} = V_{CC} - I_{CQ}R_c$ | 输出回路 KVL |

### 6.2 易错点提醒

1. **两种通路画法原则不要混**：直流通路电容开路；交流通路大电容短路、无内阻直流电源短路。直流通路里电容开路≠交流通路里也开路，反之亦然。
2. **$U_{BEQ}$ 是近似常数**：硅管 $0.6\sim0.8\ \mathrm{V}$、锗管 $0.1\sim0.3\ \mathrm{V}$，估算时直接当已知量用，不要列方程去解它。
3. **测试必须在不失真前提下**：放大倍数、最大输出功率等指标的测量，都要先用示波器确认输出波形不失真。
4. **负载变小，电压增益变小**：由 $A_u = A_{vo}\frac{R_L}{r_o+R_L}$ 可知增益随 $R_L$ 减小而下降——这正是希望 $r_o$ 小的原因。
5. **耦合电容容量要足够大**：容量太小，信号低频分量衰减大；只有容量足够大，动态时电容上电压才可视为不变，信号才能完整驮载到静态之上。

### 6.3 解题要点

- **判断电路能否正常放大**：拿四条组成原则逐条对照——放大状态（e 结正偏 c 结反偏）、信号进得来、信号出得去、有合理 Q 点。
- **静态估算三步走**：画直流通路 → $I_{BQ} = \frac{V_{CC}-U_{BEQ}}{R_b}$ → $I_{CQ}=\beta I_{BQ}$、$U_{CEQ}=V_{CC}-I_{CQ}R_c$。
- **分析动态先想"驮载"**：任何一点的瞬时值 = 直流分量 + 交流分量；输出电压只取交流分量，且共射电路输出与输入**反相**。
- **区分三个"电阻"**：$R_b$、$R_c$ 是电路里的真实电阻；$r_i$、$r_o$ 是从端口看进去的**交流等效电阻**，两者不能混为一谈。

:::tip[学习建议]
把"直流定工作点、交流算增益"当成分析放大电路的口诀：拿到电路先分直流通路与交流通路，静态用估算法，动态等学完 h 参数微变等效电路再算——但直流通路这一步永远是第一块多米诺骨牌。
:::
