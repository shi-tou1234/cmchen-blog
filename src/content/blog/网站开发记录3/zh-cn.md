上一回写到7月3号，我在结尾说：这个项目可能永远不会做完。

一个多月过去了。它确实没做完，但这次干的活跟以前不一样——我把它开源了。

不是开源个随手的小东西，是把写了半年的博客收拾干净，做成一套别人能直接拿去用的模板，放到了 GitHub 上。

事情是这样的。

* * *

先说个最丢人的事。

我这个博客的仓库，在 GitHub 上的名字，之前一直是一个横杠。就一个"-"。

对，减号。（现在想想都觉得离谱。）

我也不知道当初怎么起的这个名字，估计建仓库的时候随手敲的。然后这个减号就跟了我快半年——你去翻我的合并提交记录，里面全是 `shi-tou1234/-`。我博客这半年的家，叫"减号"。

直到8月9号，我才终于给它改了名，叫 cmchen-blog。顺便把仓库里所有写死的 `/-` 引用全部换掉：部署路径的 base、关于页的音乐文件、还有 git remote 自己。改完推上去，线上样式直接 404 白屏——base 还指着旧路径，CSS 和 JS 全找不到。又修了一版才算稳。

改个名都能白屏一次，也是没谁了。

* * *

不过改名只是开头。真正的大动作，是我把仓库开源成了一个初始化版本，叫 cmchen-blog-starter。

这事的想法特别朴素。

我的博客，从2月16号开始，123天做到932次提交，到今天1134次，一行代码都没自己写过，全是 AI 写的。它整套功能都是现成的：后台管理、公式渲染、全文搜索、旅行地图、中英双语。这样的东西，把我的个人内容删干净，不就是一套现成的博客模板吗。

文章、关于、工具栏链接、旅行地图城市标记、音乐播放器，全删。只留下完整的功能和工程配置。别人克隆下来，填上自己的内容，改一下部署地址，就是一个功能齐全的博客。

当时想的是：说不定有人跟我一样，想用 AI 搭个博客又不知道从哪开始。那这个 starter 就是他的起点。

开源之前还干了件挺正式的事——换 LICENSE。

原仓库的 LICENSE 是从 Momo 主题那边克隆的时候一起带过来的，版权行写着 `Copyright (c) 2025 Motues`。（那个文件我从没点开看过，那天才发现写的是别人的名字。）你拿别人的许可证开源自己的项目，说不过去。删。换成 `Copyright (c) 2026 cmchen` 的 MIT。

一个删一个加，中间隔了5分钟。

然后我又把 README 从原来那几行字，扩成了一份正经文档：项目概述、功能特性、技术栈、目录结构、安装指南、部署说明，全给补上了。

写完 README 里 starter 那段介绍，我顺手又给后台补了两个编辑器——站点信息编辑器（标题、标语、创建时间）和首页签名编辑器（首页那行打字机的字，可以后台改了）。

开源前把后台补全。大概是一种仪式感。

* * *

不过，要把这个博客推出去见人，光改名和换 LICENSE 不够。开源前那几天，我其实都在"收拾房子"。中间还夹着几篇新文章、一次把浅色主题换成暖黄色的配色，这些不细说。

8月2号算一个节点。17次提交，下午到晚上。先是修了12个 bug 和安全项——包括我第一次处理的安全问题，目录穿越和文件头注入。然后是一场大清理：删掉了一整套 Svelte。

对，整套。Svelte 是什么时候被我塞进项目的，我已经不记得了，大概是哪个功能要用到，用完就一直躺着，集成、依赖、配置、页脚图标，全套。还有一堆写了但没人用的死代码、失效的兜底函数、过时的文档。

这活干的时候没什么感觉，就是删。但删完之后我发现，这个博客的代码，第一次可以见人了。以前它就是一堆 AI 往上面堆的东西，堆的时候没人想过以后会有人打开源码看。开源逼着我把家里收拾干净。

收拾的过程中还干了一件特别无聊的事：给39个文件里的 CSS 变量改名。`--button-hover-color` 改成 `--hover-bg-color`——因为那个变量实际用在卡片、代码块、芯片上，不只是按钮。一个值都没改，只改名字。

我盯着那39个文件的 diff，第一次体会到什么叫代码洁癖。

哦对了，还有 CI 里那个假检查。类型检查和代码规范检查，都设了 `continue-on-error`——检查失败也照样部署。检查了，但失败无所谓。这不叫检查，这叫假装在把关。我盯着看了很久，把它删了。

开源这件事最神奇的地方在于：它把我这半年的"差不多就行"，全逼成了"不行，得弄干净"。

* * *

收拾房子之外，开源前那阵子还补了两件我自己最想要的东西。

一件是公式推导浮层。

我的笔记全是数学物理公式。期末复习的时候，最恨的就是一个定理摆在你面前，只有结论，没有过程——"这个结论哪来的"。所以我一直想要一个功能：鼠标悬停在公式上，弹出来它的完整推导。

7月10号真做出来了。功能本身一天写完，麻烦的是给内容补推导——48篇笔记，数学的物理的电路的，一篇一篇找关键定理，补推导过程，一共650个。

650个。这活要是纯手写，我现在还在写。

另一件，是我第一次认真搞安全。

以前我不懂什么叫安全。后来 AI 给我审代码，审出一堆问题，分了三档：P0、P1、P2。P0 里最吓人的一个是，登录有个硬编码密码回退——安全配置加载失败的时候，自动落到一套写死的默认密码上。逻辑是"配置坏了你还能进去"，但代价是：谁拿到源码，谁就拿到了密码。删。加载失败就禁用登录，宁可进不去，不能裸奔。

那阵子我补了一堆以前从来没听过的名词：XSS、Open Redirect、PBKDF2。PBKDF2 是密码哈希算法，迭代次数从18万提到60万，据说是 OWASP 标准。你只需要知道：同一个密码，以前要算18万次才能验证，现在要算60万，暴力破解的成本翻了三倍多。

还有 GitHub Token，从 localStorage 挪到 sessionStorage——关标签页就清空。结果我用了两天就嫌烦，天天重新登录。又加了个「记住 Token」复选框，勾上就存永久。

先为安全挪走，又为了方便加回来。安全与便利打架，打到最后 AI 给的方案是：都给你，你自己选。

* * *

最后放一组数据吧，给这一个多月做个注脚：

时间跨度：07.04 - 08.09

提交次数：110次（总提交 1134 次）

最重的一天：08.02，17次提交，12项 bug/安全修复加一场大清理

最涨知识的一天：07.09，P0/P1/P2 安全修复，听过的安全名词排了半页

删得最狠的一次：整套 Svelte + 全套死代码

最无聊的一次：39个文件，只改 CSS 变量名

最隐蔽的坑：预览里的图全裂，raw 链接在国内被墙（旧文章182处引用）

最抽象的仓库名："-"

最正式的一个瞬间：删掉 Motues 的 LICENSE，换上自己的 MIT

最骄傲的一件事：我把这个博客开源了，它叫 cmchen-blog-starter

* * *

上回我说，这个项目可能永远不会做完。现在它确实没做完——我甚至还在往里面加功能，比如那两个后台编辑器。

但这次我想通了一件事。

以前我觉得，一个项目要"做完"才算有价值。现在我觉得，一个东西能不能从你的手里走到别人手里，才是另一回事。

我的博客从"-"变成了 cmchen-blog，从个人仓库变成了别人的起点。它还是没做完，但它的生命，好像比"做完"更长了。

这次就先写到这儿吧。

下次再写《网站开发记录》，可能是哪天我又把它折腾散架了，也可能是我发现有人真的在用 cmchen-blog-starter 搭博客的那天。

谁知道呢。

反正代码不会自己跑，bug不会自己好。

而我，大概率明天还会让 AI 帮我改代码。
