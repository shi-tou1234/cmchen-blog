# 二极管应用电路

> **导语**：本文整理半导体器件一章中二极管应用电路的典型内容：先用理想模型与恒压降模型分析限幅电路的输出波形，再用叠加定理分析含直流与交流电源的二极管电路，接着进行小信号（微变等效）分析，然后给出判断二极管通断状态的开关电路，最后系统梳理稳压二极管的稳压原理、伏安特性、工作条件与六个主要参数。文末附核心公式速查、易错点提醒与解题要点，适合期末复习或考研参考。

* * *

## 一、 限幅电路

### 1.1 例题与电路结构

**题目**：$R = 1\,\mathrm{k\Omega}$，$V_{REF} = 3\,\mathrm{V}$，二极管为硅二极管。分别用理想模型和恒压降模型求解：当 $v_I = 6\sin\omega t$ V 时，给出相应的输出电压 $v_O$ 的波形。

> 电路描述：输入端标 $v_I$（上端 +、下端 −）；上端支路串联电阻 $R$ 后接输出上端（输出端标 $v_O$，上 +、下 −）；从输出上端节点经二极管 D（阳极在上、阴极在下，箭头朝下）与直流参考电源 $V_{REF}$（正极在上）接到下端公共线。

二极管 D 的阳极接输出上端，阴极经参考电源 $V_{REF}$ 接下端公共线，因此 D 两端的阳极-阴极电压可由输出电位与参考电平相减得到：

$$ v_{AK} = v_O - V_{REF} $$

可见，只有当输出电位高于参考电平时 D 才可能正向导通；导通后输出被"钳"在参考电平（再加上正向压降）上，正弦波超出的部分被削平，这就是限幅作用。

:::derivation
**分析（两种模型的削平电平）：**

- **理想模型**：理想二极管导通压降为零，当 $v_{AK} \geq 0$ 即 $v_O \geq V_{REF} = 3\,\mathrm{V}$ 时 D 导通，输出被钳在 $v_O = 3\,\mathrm{V}$；$v_O < 3\,\mathrm{V}$ 时 D 截止，输出跟随输入。
- **恒压降模型**：二极管等效为理想二极管串联压降源 $V_D = 0.7\,\mathrm{V}$，当 $v_O \geq V_{REF} + V_D = 3.7\,\mathrm{V}$ 时 D 导通，输出被钳在 $v_O = 3.7\,\mathrm{V}$。
:::

### 1.2 理想模型：削平到 3 V

**等效电路**：二极管支路只含理想二极管 D（箭头朝下）与 $V_{REF}$ 电源串联，其余部分与原电路相同。

**解：**

- 正半周中 $v_O$ 达到 $3\,\mathrm{V}$ 以上时，D 正向导通、压降为零，$v_O$ 被削平为 $3\,\mathrm{V}$ 的水平线；
- 其余时间（低于 $3\,\mathrm{V}$ 的部分，包含整个负半周），D 截止，$v_O$ 跟随 $v_I$ 的正弦形状变化。

**输出波形描述**：纵轴为 $v_O/\mathrm{V}$，标刻度 $0$、$3$；横轴为 $\omega t$，标刻度 $\pi$、$2\pi$、$3\pi$、$4\pi$。虚线为输入正弦波 $v_I$（幅值高于 $3\,\mathrm{V}$），实线为输出 $v_O$：正半周顶部被削平为 $3\,\mathrm{V}$ 的水平线，低于 $3\,\mathrm{V}$ 的部分（含负半周）跟随 $v_I$ 的正弦形状变化。

### 1.3 恒压降模型：削平到 3.7 V

**等效电路**：二极管支路为二极管 D（箭头朝下）、压降源 $V_D$、$V_{REF}$ 电源依次串联，其余部分与原电路相同。

**解：**

- D 需要 $v_O$ 达到 $V_{REF} + V_D = 3\,\mathrm{V} + 0.7\,\mathrm{V} = 3.7\,\mathrm{V}$ 时才正向导通，导通后 $v_O$ 被削平为 $3.7\,\mathrm{V}$；
- 其余部分跟随 $v_I$ 的正弦变化。

**输出波形描述**：纵轴为 $v_O/\mathrm{V}$，标刻度 $0$、$3.7$；横轴为 $\omega t$，标刻度 $\pi$、$2\pi$、$3\pi$、$4\pi$。虚线为 $v_I$，实线 $v_O$ 在正半周顶部被削平为 $3.7\,\mathrm{V}$ 的水平线，其余部分跟随正弦变化。

> **对比**：两种模型电路结构相同，差别只在削平电平——理想模型为 $V_{REF} = 3\,\mathrm{V}$，恒压降模型为 $V_{REF} + V_D = 3.7\,\mathrm{V}$，高出的 $0.7\,\mathrm{V}$ 正是硅二极管的正向压降。

## 二、 叠加定理分析二极管电路

### 2.1 例题与电路结构

**题目**：若 $E = 6\,\mathrm{V}$，$u = 0.2\sin 3140t$ V，$R = 1\,\mathrm{k\Omega}$，考虑正向压降和正向特性斜率的二极管等效电路，已通过图解法求得 $r_D = 10\,\Omega$，求流过二极管的电流。

> 电路描述：上方节点 A、下方节点 B（A、B 之间为虚线，标 $U_D$，上 +、下 −）。左支路：交流电源 $u$（上 +、下 −）与直流电源 $E$（上 +、下 −）串联后经电阻 $R$ 接到 B；右支路：理想二极管 D（箭头朝下）、正向压降源 $U_{on}$、电阻 $r_D$ 依次串联接回 B；支路电流标 $I_D$（方向向下）。

**方法**：采用叠加定理——先令直流电源 $E$ 和压降源 $U_{on}$ 作用求出直流分量，再令交流电源 $u$ 单独作用求出交流分量，最后把两个分量相加。

### 2.2 直流电源 $E$ 和 $U_{on}$ 作用时

$$I_D = \frac{E - U_{on}}{R + r_D} = \frac{6 - 0.7}{1000 + 10} = 5.3\,\mathrm{mA}$$

### 2.3 交流电源 $u$ 单独作用时

$$i_d = \frac{u}{R + r_D} = \frac{0.2\sin 3140t}{1000 + 10} \approx 0.2\sin 3140t\,\mathrm{mA}$$

### 2.4 流过二极管的总电流

$$i_D = I_D + i_d = (5.3 + 0.2\sin 3140t)\,\mathrm{mA}$$

> **说明**：流过二极管的总电流由直流分量 $5.3\,\mathrm{mA}$ 与交流分量 $0.2\sin 3140t\,\mathrm{mA}$ 叠加而成。

## 三、 小信号（微变等效）分析

### 3.1 例题与电路结构

**题目**：图示电路中，$V_{DD} = 5\,\mathrm{V}$，$R = 5\,\mathrm{k\Omega}$，恒压降模型的 $V_D = 0.7\,\mathrm{V}$，$v_s = 0.1\sin\omega t$ V。（1）求输出电压 $v_O$ 的交流量和总量；（2）给出 $v_O$ 的波形。

> 原电路描述：左侧直流电源 $V_{DD}$（上 +、下 −）与交流信号源 $v_s$（上 +、下 −）串联（图中 $v_s$ 在上、$V_{DD}$ 在下）；上端支路接二极管 D（箭头朝右）、压降源 $V_D$，电流标 $I_D$（方向向右），之后接电阻 $R$ 到地，输出端标 $v_O$（上 +、下 −）。

**思路**：采用叠加定理，先分析直流通路（静态）确定 $I_D$，再分析小信号模型的交流通路（动态）求 $r_d$ 与输出交流量，最后合成总量。

### 3.2 直流通路（静态）

> 直流通路描述：$V_{DD}$ 电源（上 +、下 −）→ 二极管 D（箭头朝右）→ 压降源 $V_D$ → 电流 $I_D$（向右）→ 电阻 $R$ 接地，输出端标 $V_O$。

$$I_D = \frac{V_{DD} - V_D}{R} = \frac{5 - 0.7}{5} = 0.86\,\mathrm{mA}$$

### 3.3 小信号模型的交流通路（动态）

> 交流通路描述：交流源 $v_s$（上 +、下 −）→ 上端支路电阻 $r_d$（其上标电流 $i_d$ 向右）→ 电阻 $R$ 接地，输出端标 $v_o$（上 +、下 −）。

二极管在小信号下等效为动态电阻 $r_d$：

$$r_d = \frac{U_T}{I_D} = \frac{26}{0.86} \approx 0.03\,\mathrm{k\Omega}$$

在交流通路上用分压公式求输出交流量：

$$v_o = v_s\frac{R}{R + r_d} = 0.1\sin\omega t \times \frac{5}{5 + 0.03} \approx 0.0994\sin\omega t\ \mathrm{V}$$

### 3.4 总量与波形

输出电压的直流分量为 $V_O = 4.3\,\mathrm{V}$，与交流分量相加得总量：

$$v_O = V_O + v_o = 4.3 + 0.0994\sin\omega t\ \mathrm{V}$$

**输出波形描述**：纵轴为 $v_O/\mathrm{V}$，标刻度 $0$、$4.3$；横轴为 $\omega t$，标刻度 $\pi$、$2\pi$、$3\pi$。波形为在 $4.3\,\mathrm{V}$ 直线上下波动的正弦小信号，振幅标注为 $0.0994\,\mathrm{V}$。

## 四、 开关电路

### 4.1 例题与电路结构

**题目**：二极管假设为理想，求 AO 两端的电压值。

> 电路描述：左侧为 $6\,\mathrm{V}$ 直流电源（靠近上端处标 −），上端支路接二极管 D（箭头朝右）后到节点 A；从 A 经 $3\,\mathrm{k\Omega}$ 电阻向下接 $12\,\mathrm{V}$ 电源到节点 O；O 点接地并引出端子 O，A 点引出端子 A。

### 4.2 判断二极管的状态

**第一步，先断开 D**：以 O 为基准电位，即 O 点为 $0\,\mathrm{V}$。

**第二步，算电位**：接 D 阳极的电位为 $-6\,\mathrm{V}$，接阴极的电位为 $-12\,\mathrm{V}$。

**第三步，比较**：阳极电位高于阴极电位，所以接入 D 时二极管正向导通。

:::tip[判断二极管状态的三步法]
先断开二极管 → 以公共端（如 O 点）为基准算出二极管阳极、阴极的电位 → 比较两者：阳极电位高于阴极电位，则接入后二极管正向导通。
:::

### 4.3 结论

导通后，理想二极管 D 的压降等于零，即 A 点的电位就是 D 阳极的电位：

$$U_{AO} = -6\,\mathrm{V}$$

因此 AO 两端电压值为 $-6\,\mathrm{V}$。

## 五、 稳压二极管

**稳压二极管**（又称齐纳二极管）是应用反向击穿特性具有稳压效应的特殊二极管，主要用作稳压。

### 5.1 稳压原理与伏安特性

**伏安特性（文字描述）**：纵轴为 $I_Z/\mathrm{mA}$，横轴为 $U_Z/\mathrm{V}$。第一象限为正向特性曲线（先平后陡升）；第三象限为反向击穿段，曲线近似垂直下落。图中标注了击穿段的横向电压变化量 $\Delta U_Z$、纵向电流变化量 $\Delta I_Z$，以及 $I_{Z\min}$、$I_{Z\max}$ 和击穿段对应的电压位置 $V_Z$。

**稳压原理**：稳压管工作在反向击穿段，该段曲线近似垂直——电流在 $I_{Z\min}$ 与 $I_{Z\max}$ 之间变化时，管子两端的稳定电压 $U_Z$ 变化很小，从而实现稳压。

**符号**：稳压二极管的符号为竖直线加两端带折角的横杠，形似字母 Z；图中上端标 +、下端标 −，旁边箭头向下标 $I_Z$。

**正向特性**：正向导通时，稳压管的正向特性与普通二极管相同，其导通电压为 $0.7\,\mathrm{V}$。

### 5.2 工作条件

1. 反偏且击穿；
2. 为了保证稳压管工作在反向击穿状态，作稳压使用时必须反向加压，并且还必须加限流电阻，其作用是保证工作电流 $I_Z$ 满足 $I_{Z\min} < I_Z < I_{Z\max}$。

> 电路描述（稳压管的使用条件）：左端输入（上 +、下 −），上端支路串联电阻 $R$，右侧接稳压二极管（反接），管旁标 $+U_Z$（上）与 −（下），回路中用箭头标出电流 $I_Z$ 的环流方向。

工作电流越界时：

- $I_Z < I_{Z\min}$：稳压管进入反向饱和区，没有稳压作用；
- $I_Z > I_{Z\max}$：会引起管子过热而损坏。

### 5.3 主要参数

**（1）稳定电压 $U_Z$**：稳压管反向击穿后，通过规定电流时相应的电压值。

对于硅管而言，不同 $U_Z$ 表现为不同的击穿机理：

| 条件 | 击穿机理 | 说明 |
| :--- | :--- | :--- |
| $U_Z > 7\,\mathrm{V}$ | 雪崩击穿 | 反向电压加大，空间电荷区电场很强，少子获得足够高的能量与价电子碰撞，产生新的电子-空穴对又去碰撞别的价电子，继续产生新的电子-空穴对，载流子个数成倍增加，电流剧增 |
| $U_Z < 4\,\mathrm{V}$ | 齐纳击穿 | PN 结很薄，无须很大的反压就可以产生强电场作用，将价电子拉出参加导电，使电流剧增 |
| $4\,\mathrm{V} < U_Z < 7\,\mathrm{V}$ | 二者都有 | —— |

例如 2CW11：$3.2\,\mathrm{V} < U_Z < 4.5\,\mathrm{V}$。

**（2）最小稳定工作电流 $I_{Z\min}$**：指稳压管具有正常稳压作用的最小稳定电流。稳压使用时要求 $I_Z > I_{Z\min}$。

**（3）最大稳定工作电流 $I_{Z\max}$**：指稳压管具有正常稳压作用时的最大稳定电流。稳压使用时要求 $I_Z < I_{Z\max}$。

**（4）动态电阻 $r_Z$**：指稳压管两端电压的变化量 $\Delta U_Z$ 与所对应的电流变化量 $\Delta I_Z$ 之比值：

$$r_Z = \frac{\Delta U_Z}{\Delta I_Z}$$

它是描写反向击穿线垂直程度的参数：$r_Z$ 越小，击穿线越垂直，稳压性能越好。理想的稳压管 $r_Z = 0$。

**（5）额定功耗 $P_{ZM}$**：由稳压管允许温升决定的参数，其大小为：

$$P_{ZM} = U_Z \cdot I_{Z\max}$$

**（6）稳定电压的温度系数 $\alpha_Z$**：反映稳定电压 $U_Z$ 受温度影响的参数：

$$\alpha_Z = \frac{\Delta U_Z}{U_Z \cdot \Delta T} \times 100\% / ^\circ\mathrm{C}$$

不同 $U_Z$ 范围的温度系数：

| $U_Z$ 范围 | 温度系数 |
| :--- | :--- |
| $U_Z > 7\,\mathrm{V}$ | 正温度系数 |
| $U_Z < 4\,\mathrm{V}$ | 负温度系数 |
| $4\,\mathrm{V} < U_Z < 7\,\mathrm{V}$ | 温度系数最小 |

### 5.4 稳压电路例题

**题目**：$v_I$ 为正弦波，且幅值大于 $V_Z$，试定性画出 $v_O$ 的波形。

> 电路描述：左侧输入 $v_I$（上 +、下 −）；上端支路串联电阻 $R$，$R$ 下方标电流 $I_R$（向右）；从 $R$ 后的节点经稳压二极管 $D_Z$（阴极在上、阳极在下，下端接地）支路到地，该支路标电流 $I_Z$（向下）；节点向右引出电流 $I_O$（向右），右端接负载电阻 $R_L$（上端接上导线、下端接地），输出端标 $V_O$（上 +、下 −）。

**波形描述**：上图为 $v_I$ 随 $\omega t$ 变化的蓝色正弦波，图中有一条水平虚线标 $V_Z$（位于横轴上方）；下图为 $v_O$ 随 $\omega t$ 的波形：顶部被削平（削平处与上方虚线 $V_Z$ 对齐，用竖直虚线对应），底部也被削平，削平之间的部分随正弦变化，整体呈近似梯形脉冲波。

**结论**：正常稳压时 $V_O = V_Z$。

:::note[课件内容小结]
- 普通二极管只有一个 PN 结，主要特点是**单向导电性**，即正偏导通、反偏截止。
- 描写单向导电性有两种方法：一是电流方程式，二是伏安特性曲线。
- 伏安特性曲线分为四个区：线性工作区、死区、反向饱和区和反向击穿区；二极管正向导通时应工作在线性工作区。
- 稳压二极管的特点是**稳压效应**，主要用作稳压，使用时必须反向接，还须加限流电阻。
:::

## 六、 总结与注意事项

### 6.1 核心公式速查

| 内容 | 公式 / 结论 | 说明 |
| :--- | :--- | :--- |
| 限幅电平（理想模型） | $v_O = V_{REF}$ | 本例削平到 $3\,\mathrm{V}$ |
| 限幅电平（恒压降模型） | $v_O = V_{REF} + V_D$ | 本例削平到 $3.7\,\mathrm{V}$ |
| 叠加定理（直流分量） | $I_D = \frac{E - U_{on}}{R + r_D}$ | 本例 $5.3\,\mathrm{mA}$ |
| 叠加定理（交流分量） | $i_d = \frac{u}{R + r_D}$ | 本例 $0.2\sin 3140t\,\mathrm{mA}$ |
| 小信号电阻 | $r_d = U_T / I_D$ | 本例 $\approx 0.03\,\mathrm{k\Omega}$ |
| 交流输出（分压） | $v_o = v_s \frac{R}{R + r_d}$ | 本例 $0.0994\sin\omega t\,\mathrm{V}$ |
| 总量 | $v_O = V_O + v_o$ | 直流分量 + 交流分量 |
| 动态电阻 | $r_Z = \Delta U_Z / \Delta I_Z$ | 越小，稳压性能越好 |
| 额定功耗 | $P_{ZM} = U_Z I_{Z\max}$ | 由允许温升决定 |
| 温度系数 | $\alpha_Z = \frac{\Delta U_Z}{U_Z \Delta T} \times 100\%/^\circ\mathrm{C}$ | 反映 $U_Z$ 受温度影响 |
| 稳压工作条件 | $I_{Z\min} < I_Z < I_{Z\max}$ | 反偏击穿，须加限流电阻 |
| 正常稳压 | $V_O = V_Z$ | 稳压电路输出电压 |

### 6.2 易错点提醒

1. **限幅电平不能混用**：理想模型削平到 $V_{REF} = 3\,\mathrm{V}$，恒压降模型削平到 $V_{REF} + V_D = 3.7\,\mathrm{V}$，高出的 $0.7\,\mathrm{V}$ 正是硅二极管的正向压降。
2. **叠加定理的分量要分清**：直流电源 $E$、$U_{on}$ 作用时求直流分量 $I_D$，交流电源 $u$ 单独作用时求交流分量 $i_d$，最后相加得总电流 $i_D$。
3. **小信号分析先静后动**：先用直流通路求 $I_D = 0.86\,\mathrm{mA}$，再由 $r_d = U_T / I_D$ 求小信号电阻，最后在交流通路中求输出交流量。
4. **二极管通断要"先断开再判断"**：以公共端为基准算出阳极、阴极电位再比较，不能凭直觉判断；本例阳极 $-6\,\mathrm{V}$ 高于阴极 $-12\,\mathrm{V}$，故正向导通。
5. **稳压管必须反向接、加限流电阻**：工作电流须满足 $I_{Z\min} < I_Z < I_{Z\max}$；$I_Z$ 过小会进入反向饱和区而失去稳压作用，过大则过热损坏。
6. **稳压管正向工作时**：特性与普通二极管相同，导通电压为 $0.7\,\mathrm{V}$；作稳压使用必须反向偏置、工作在击穿区。

### 6.3 解题要点

- **限幅电路**：抓住"导通钳位、截止跟随"两种支路状态，再按所用模型确定削平电平。
- **含直流与交流的二极管电路**：用叠加定理分而治之——直流求分量、交流求分量、最后相加。
- **小信号（微变等效）分析**：直流通路求静态 $I_D$ → $r_d = U_T / I_D$ → 交流通路分压求 $v_o$ → 总量 $v_O = V_O + v_o$。
- **开关电路**：先断开二极管 → 以公共端为基准算电位 → 比较阳极、阴极电位判断通断；理想二极管导通后压降为零。
- **稳压电路**：确认稳压管反偏击穿、工作电流在 $I_{Z\min} \sim I_{Z\max}$ 之间，正常稳压时输出电压 $V_O = V_Z$。

:::tip[学习建议]
处理二极管电路的通用节奏：先判断二极管状态（导通还是截止），再按对应模型写出定量关系，最后分段或分交、直流求解并合成输出。记忆口诀：限幅看钳位、叠加分交直、小信号先静态、开关先断开、稳压反偏加限流。
:::
