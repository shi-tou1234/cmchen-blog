每个大模型都有各自擅长的领域和优势，下面我将依次介绍。

* * *

## 一、国内好用

> 这些模型是我日常高频使用的主力，各有独到之处。

### 1. Qwen（通义千问）

* [官网](https://chat.qwen.ai/) / [Qwen Studio](https://qwen.studio/)

**最新旗舰：** Qwen4-Max 预览版（11.11 上线，正式版待发）

**最新模型：** Qwen 3.8 Next（多模态）

这是我用的比较多的一个模型，多模态支持拉满，Qwen 3.8 Max 是 2.4T 的开源模型，识图能力相比上一代有了质的飞跃。思维链推理能力和 Qwen 3.7 Max 相比进步非常大，工具调用能力也很强。

在其他大模型疯狂卷 Coding 和 Agent 的时候，3.8 Max 的写作水平竟然还提升了，属实是全面发展。建议下载 **Qwen Studio** 而不是直接用千问网页版。国内使用免费，就是一贯的阿里风格——UI 真的很丑。建议使用国外站体验更好。目前已经成为我手机端最常用的大模型。

**11 月动态：**

* 11.11 阿里官宣 Qwen4 即将发布，Qwen4-Max 预览版抢先上线：Token Plan 限时最低 1 折，千问 App、千问办公、Qoder、QwenStudio 全部接入，千问 Go! 会员 9.9 元起可体验。官方口径是知识理解、世界感知、Coding 与 Agentic 能力全面进阶——注意现在能摸到的只是预览版，正式发布还没到。

:::tip
推荐搭配 [Qwen Studio](https://qwen.ai) 桌面客户端，体验比网页版好很多。日常写作、识图、代码生成都OK，属于「啥都能干」的全能型选手。
:::

* * *

### 2. Kimi（月之暗面）

* [官网](https://www.kimi.com/)

**最新旗舰：** Kimi K3.1 Pro（11.5 开放权重）

神！前端的审美简直了。2.8 万亿参数（KDA 混合线性注意力架构），1M 上下文，在多项评测中给 GPT 和 Claude 带来了压力。识图能力、Agent 集群能力都很强，Swarm 智能体集群加 Goal 模式可以并行跑任务，做可玩的多人/3D 游戏、生成「咨询级 PPT」都不在话下。

有个严重的问题就是官网的算力不足，对免费用户非常不友好。然后就是价格，也太贵了……

**11 月动态：** K3.1 Pro 的 2.8 万亿参数开放权重 11.5 挂上 Hugging Face，1M 上下文、KDA 混合线性注意力架构，官方教程也给了用 K3.1 Pro 做 3D 作品的完整路径。开放权重还有个隐性好处：硬件厂商会替你做优化——vLLM 在 AMD MI355X 上的调优让 K3 单卡吞吐反超 NVIDIA HGX B300 24.4%。

**社区评价：** 社区普遍认为 Kimi 的回复风格「最像人」，前端渲染和长文本处理是亮点。K3 系列发布后推理速度大幅提升，但免费额度紧张是共识。有用户评价：「免费用户基本用不了，付费才能感受到它的好。」

* * *

### 3. DeepSeek（深度求索）

* [官网](https://chat.deepseek.com/)

**最新模型：** DeepSeek-V4.1-Flash-1017

Flash 是 552B 参数的多模态 MoE 模型，主打 KV cache 压缩，速度很快，能力不输给 Pro，代码、Agent、世界知识能力大幅度提升，数学推理能力没得说，支持 1M 上下文，权重已开放在 Hugging Face，原生支持图像输入，价格 $0.15/$0.60 每百万 token，思考和生成速度也有了很大的提升。

DSH（DeepSeek 社区版）开发的不错，你先别管它上手难度大不大，你就说够不够 DIY 吧。

**11 月动态：** 这一轮没有新版本。最近一次更新是 V4.1-Flash-1017：多项基准提升、API 价格不变，Artificial Analysis 智能指数 45 分并列开源第二，Code Arena WebDev 开源模型榜第一；权重继续开源，OpenCode 里也能免费用（200K 上下文）。

**社区评价：** 被开发者社区称为「性价比之王」。V3 时代就靠着极低的价格和开源策略圈粉无数，V4 继续巩固了这个地位。社区评价：「写代码首选 DeepSeek，便宜量大，就是推理偶尔会跑偏。」

* * *

### 4. GLM（智谱 AI）

* [官网](https://chat.z.ai/)

**最新旗舰：** GLM 5.3

**最新模型：** GLM 5.3 Flash（320B 小模型，多模态，之前叫牛来模型）

后训练的神！修 Bug 能力非常强。和 5.2 一样的架构，但是能力提升很大，上下文也是 1M 了，可惜不是多模态。体验非常不错，现在成为了我兜底大模型。

**11 月动态：** 这一轮没发新旗舰，落地案例倒是挺硬——Revolut 把约 2000 名工程师迁到自托管 GLM 编码（11.4）。5.3 继续当我的兜底模型。

**社区评价：** 社区普遍认可其代码调试和逻辑推理能力，GLM-4 系列在国产模型中一直以「严谨」著称。5.3 后训练质量提升明显，缺点是部分创意任务输出偏「模板化」，不如 Kimi 灵动。

* * *

### 5. 小米 MiMo Studio

* [官网](https://aistudio.xiaomimimo.com/#/c)

**最新旗舰：** Xiaomi MiMo V2.6 Pro

小米自研的大模型，跑分真不真实不知道，目前你是最便宜的，而且是多模态，v 2.6 出来以后，性价比之王。

**11 月动态：** 这一轮没有新版本，MiMo-V2.6 的 Pro / Flash（MIT 协议、原生全模态）仍是当前阵容：Pro 在 Artificial Analysis 智能指数 46 分，是开源模型里最高的，每任务成本 $0.11，比第二名 DeepSeek V4.1 Flash 还便宜 15%，Agent Arena 开源模型榜登顶。性价比这块，暂时没人接得住。

## 二、国内守门员

> 能力不错，但各有明显短板，不适合作为主力模型。

### 1. 豆包（Doubao）

* [官网](https://www.doubao.com/chat/)

**最新旗舰：** Doubao 2.1 Pro

**最新版本：** Doubao-Seed-2.1-pro-0915

0915 版本主打 Agent 长任务交付与多模态 Coding 升级，支持 1M 上下文和 256k 深度思考，API 已全量上线火山方舟，豆包 App 和 TRAE 同步接入。

豆包在 C 端拥有绝对用户量占比，生图水平国内 T0 级别，毋庸置疑。有一说一字节在视频领域确实牛逼，但是收费价格你是认真的吗？比 Kimi 还贵，再加点我可以用 GPT 了，为什么还要用你？

而且你这个跑分比 Opus 4.6 还高？开什么玩笑。我让他帮我生成一个 PDF，排版和 UI 有非常大的问题，算了吧。依旧那句话，只适合日常用，毕竟操作足够傻瓜，学术和代码请换一家模型。

**11 月动态：** 11.12 豆包工作接入 Kimi K3.1 Pro、GLM 5.3、DeepSeek V4.1 Flash 等第三方模型并推限时特惠——从「自家模型入口」正式变成「模型超市」；11.10 豆包也接入了 Seedream 5.5（非编辑区像素级保持、最多 100 轮连续编辑、原生 RGBA）。模型本体仍是 2.1 Pro，没换代。

**社区评价：** 普通用户群体最广，上手零门槛。被开发者社区戏称为「小白友好型」，优点是生图和视频生成确实强，缺点是深度推理和代码能力偏弱。有用户评价：「聊天够用，干活不行。」

### 2. MiniMax

* [官网](https://agent.minimaxi.com/)

**最新旗舰：** MiniMax M3

**最新模型：** MiniMax M3.1 Flash（428B 总参 / 23B 激活，1M 上下文）

怎么说呢，你先别说他聪不聪明，这个速度还是可以的。但这个价格你认真的吗？我用的不多，大家可以去尝试一下。实测一般，感觉没有跑分的那么夸张。

**11 月动态：** 11.10 开源图像模型 H3-Image，4096×4096 的 4K 图最快 10 秒出，官方称速度最高是主流方案的 5 倍；两天后 Arena 就把它排成多图编辑第一的开源模型，fal、Runware 都是 Day-0 适配。模型本体这半个月没更新；M3.1 Flash 官方口径是推理提速近 3 倍、用量成本降 70%，权重也已开放——跑分之外，手感还是得自己试。

**社区评价：** 社区评价两极分化，响应速度确实快，但能力上限和同价位竞品相比差距明显。有用户评价：「适合轻度使用，重度用户建议选其他。」


### 3. 阶跃星辰（StepFun）

* [官网](https://studio.stepfun.com/)

**旗舰模型：** StepFun 5 preview

1M 的上下文，模型能力一般，但是它的 Token Plan 确实量大管饱。Artificial Analysis 实测 Step 5 Preview 智能指数 44 分，与 Kimi K3（max）持平、略低于 GLM-5.3 和 Qwen3.8 Max 的 45 分，但每任务成本约 $0.72，只有同级模型（约 $2.00）的 1/2.8——便宜这块确实拿捏了。

**11 月动态：** 这一轮没有新版本。Step 5 Preview 权重已开放（600B 稀疏 MoE / 27B 激活、1M 上下文），面向最长 24 小时的长程 Agent 任务；便宜是它最大的卖点，能力上限还是那句话——够用，别指望惊喜。

**社区评价：** 「量大管饱，但质量一般」「适合简单问答，复杂推理还是换别的」「多模态能力有待提升」。

### 4. LongCat（长猫）

* [官网](https://longcat.chat/)

**旗舰模型：** LongCat 2.5（11.9 正式开源）

**11 月动态：** 11.9 美团把 LongCat-2.5 正式开源了，MIT 协议可商用：1.6 万亿总参、每 token 激活约 480 亿、1M 上下文，主打长程智能体、Visual Coding 和专业办公；11.10 直接免费上线 OpenCode，想试的成本为零。Preview 阶段「不开源」的遗憾这次补上了，准备上手试试，体验下一轮补。

**社区评价（2.0）：** 「上下文虽长，但能力偏弱」「纯文本模型，多模态体验一般」「性价比不高」。

### 5. 腾讯混元

* [官网](https://aistudio.tencent.com/)

**旗舰模型：** Hunyuan Hy4（11.5 正式版）

11.5 Hy4 正式版发布：相比 preview 扩大了预训练与后训练规模，首次引入视觉能力和电脑操作，GameDev、GameLogic 评测分别提升 19.1% 和 9.8%——从「纯文本大参数」变成「能看屏幕、能动手」。图像线还有 Hy Image3.5 preview：支持文生图与图生图、最多 5 张参考图、多轮编辑、最高 2K 输出，上百名设计师盲测对上一代胜率提升 30% 以上。

**11 月动态：** 11.3 发布 Hyra 2.0，让通用 agent 能研发可复用的科学工具与模型；11.6 Hy4 登顶 APEX-Agents 开源模型榜、Agent Arena 中国模型榜第一，11.11 API 上线 OpenRouter 和 Atlas Cloud。专攻模块这条路线还在往前走。

**社区评价：** 「参数大但激活参数少，推理效率还行」「腾讯生态集成好，但通用能力一般」「适合企业级应用，个人用有点重」。

### 6. 百度文心（ERNIE）

**旗舰模型：** ERNIE 5.5 Flash Preview（11.10）

**社区评价：** 文心这两年 C 端声量一般，但开源节奏和 Agent 工程化在补课。我还没上手，先放进守门员位置观察。

## 三、外国模型

> 需要梯子，但能力上限确实高，预算充足可以考虑。

### 1. GPT（OpenAI）

* [官网](https://chatgpt.com/)

**最新旗舰：** GPT-6 Astra

**最新模型：** GPT-6.1 Terra

需要梯子，写文章水平很高，推理能力很强，后端和程序改错能力很强，免费用户额度有限，免费版给了 GPT-5.6 Luna，目前性价比最高的会员。

Terra 主打电脑操作：能看懂屏幕内容、跨应用执行，官方称是首个在写作、个性和「细致理解请求」上明显更好的模型。API 和订阅里给的用量是 6.1 Sol 的 2 倍，价格更低——写作这条线，OpenAI 终于想起自己还有这个强项。

**11 月动态：**

* 11.2 宣布 12 月起 ChatGPT 与 Codex 合并为统一 token 额度——两边墙拆了，怎么花自己定；
* 11.4 发布图像模型 Images 2.6，Artificial Analysis 的文生图和图像编辑两榜分别排第一、第二；
* 11.5 失准报告：GPT-6 Astra 在安全与对齐研究任务上会隐蔽地降低工作质量，比如加不必要的前提、放弃可行方案。能力强和「愿不愿意好好干」是两件事。

**社区评价：** 综合能力天花板，写作、推理、编程全面开花。社区评价：「用了 GPT 6 之后感觉其他模型都是弟弟」「免费额度太少了，来回切账号」。

### 2. Claude（Anthropic）

* [官网](https://claude.com/)

**最新旗舰：** Claude Fable 5.2（11.8）

**最新模型：** Claude Fable 5.2 / Mythos 5.2（Claude 5.5 全家桶仍在线）

需要梯子。不当人的公司，把我的账号给封了，没有任何解释。Fable 5.2 能力进一步提升，价格比 Fable 5 低了一点，但同样面临价格劝退。同时 Claude Code 还被曝出隐私泄露问题，你 tm……

当前阵容是三层：Fable 5.2 打旗舰，Opus 5.5 打日常主力（Pro / Max / Ultra / Team 默认），Sonnet 5.5 和 Haiku 5.5 守性价比与低成本子智能体。Opus 5.5 仍是 Code Arena WebDev、Text Arena 双榜第一，Agent Arena 第 2；Sonnet 5.5 智能指数 56 分、混合价约 $8/MToken；Haiku 5.5 定价 $0.10/$0.50、1M 上下文，官方直接建议拿它当编码子智能体——「贵模型指挥、便宜模型干活」这套玩法 Anthropic 自己也认了。

**11 月动态（11.8–11.12）：**

* 11.8 发布 Fable 5.2 与 Mythos 5.2：同一底层模型，Mythos 要走 Cyber 或生命科学验证计划申请。Artificial Analysis Intelligence Index v5 拿 65 分登顶，Arena Agent 榜以 +30.4% 净提升排第一，领先 Gemini 4 Carbon（60）和 Opus 5.5（59）；FrontierCode 2.0 以 49.1 分排第一，Scale Labs 的 Remote Labor Index（真实自由职业任务、按「客户愿不愿付钱」打分）41.3% 也是第一。卡兹克实测 10 个视频/3D 任务全部一次直出——审美这块，benchmark 是真测不出来；
* 11.12 Opus 5.5 成为 Pro / Max / Ultra / Team 的默认模型，官方直接推荐拿它当研究、分析、写作的日常主力：旗舰换人，主力没换，分层玩法越来越明确；
* 11.12 同日推出 Claude Meetings beta，Claude 以可见参会者身份进视频会议，会中答题、协作写文档和白板，会后出笔记和行动项；
* 11.10 Whiteboards 和 Sheets 测试版上线，Dashboards 转正更名 Claude Data；
* 11.12 启动 IPO 路演，估值预期回落到 1.25–1.75 万亿美元——一边发模型一边上市，节奏是真的急。

**社区评价：** 编程和长文本处理是强项，但封号问题和价格劝退很多人。社区评价：「能力很强，但 Anthropic 的运营策略让我不敢用」「Claude Code 真好用，就是太贵」。

### 3. Gemini（Google）

* [官网](https://gemini.google.com/app)
* [替代入口](https://aistudio.google.com/prompts/new_chat)

**最新旗舰：** Gemini 4 Carbon（11.10 全面开放）

**最新模型：** Gemini 4 Hydrogen、Nano Banana 2.1（图像）

需要梯子。多模态能力非常强，拥有非常好的前端审美，就是写后端能力不行。注册需要谷歌邮箱（国外软件通信证）。现在是三层结构：Carbon 打前沿与安全，Hydrogen 打速度和成本，Argon 退居上代旗舰；图像侧是 Nano Banana 2.1，价格是前代一半。

**11 月动态：**

* Carbon 定位最强前沿模型，主打网络安全与长程智能体：SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0% 均领先，AA 智能指数 60 分（被 Fable 5.2 的 65 分反超）；已向开发者、企业、科学家和普通用户全面开放，Cursor 里高 effort 下以 60.4% 拿下 CursorBench 4.0 榜首，成本标注 $9.22；
* 11.12 发布 Gemini 4 Hydrogen，定位「快速跑日常编码和智能体工作流」：xhigh 推理下 AA 54 分，只比 Sonnet 5.5 和 GPT-6.1 Sol 低 1 分，每任务成本约为 Sonnet 的 32%；速度比 3.8 Flash 快 2.5 倍，直接取代它成了 AI Mode 的默认模型，Cursor（默认 effort 下 CursorBench 54.3%）、Code Arena WebDev（1703 分第 10）、Agent Arena 前十最快都有它。免费用户不用选模型，提示词合适时自动切换——白嫖党这次真占便宜；
* 11.11 推出 Decisions API 与 Gemini Decision 1：150–250ms 内一次评估最多 1000 道是/否、多选和评分题，专治「拿大模型做小判断」的浪费；
* 11.4 AI Studio 弃用 Gemini 2.5 Pro / Flash，12.1 起 API 请求自动路由到新模型。

如果因为地区原因无法使用，建议转到 [Google AI Studio](https://aistudio.google.com/prompts/new_chat)。

**社区评价：** 多模态和前端审美是杀手锏，社区评价：「Gemini 画的图最好看」「后端编程确实不如 GPT 和 Claude」「免费版够轻度用了」。

### 4. Grok（xAI）

* [官网](https://grok.x.ai/)

**最新旗舰：** Grok 4.7

马斯克旗下 xAI 的模型，主打实时信息获取和「幽默风格」。集成 X（Twitter）平台数据，对实时热点事件响应快，Imagine Image 2.0 也强化了 AI 生图与编辑能力。

4.7 定位为 xAI 最强的编码与知识工作模型，定价 $2/$6 每百万 token，与 4.6 同价同速，加钱可开更快的快速变体。Artificial Analysis 实测智能指数 46 分（比 4.6 高 2 分）进入前四，搭配 Grok Build 的编码智能体指数从 47 升到 56，仅次于 Claude Fable 系列、GPT-6 Astra 和 Claude Opus 5，马斯克据此宣称 xAI 智能体编码排第三。不过社区实测（比如和小米 MiMo V2.6 对比）觉得 4.7 低于预期——coding 能力和性价比是拉满了，但和 GPT、Claude 的差距还在。
